# 馒头bot

## 项目简介

这是一个适用于 AstrBot 的馒头bot插件。

当前项目处于基础插件结构阶段，后续可继续添加具体功能。

## 项目信息

- 插件名：馒头bot
- 作者：馒头
- 仓库：https://github.com/TimShitPig/mantou_Bot
- 版本：v1.0.0

## 安装方式

将插件目录放入 AstrBot 的 `data/plugins` 目录。

然后在 AstrBot WebUI 的插件管理中重载插件。
