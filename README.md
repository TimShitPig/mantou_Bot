<details>
<summary>查看群管功能</summary>

用户发送的消息中包含连续 9 到 12 位数字时，插件会尝试撤回该消息。群名片、JSON 卡片、QQ 官方显示为“暂不能查看该消息内容”的空间相册分享、合并转发和 QQ 闪传也会走同一个撤回模块。QQ 群主和管理员发送的消息不会被自动撤回；插件会优先用 OneBot `get_group_member_info` 查询真实 QQ 群成员角色，只有查不到时才使用事件里的 `role` 兜底。普通成员当前消息撤回成功后，会通过 `get_group_msg_history` 拉取最近 100 条群历史，筛选该用户最近消息并逐条调用 `delete_msg` 撤回，默认最多撤回 8 条。

同一成员在同一个群里被本模块成功撤回 3 次后，会调用当前 OneBot 适配器的 `set_group_kick` 踢出该成员；踢出当前群成功后，会通过 `get_group_list` 获取机器人所在群，再用 `get_group_member_info` 检查该用户是否在其它群，存在则一并踢出。

群文件清理管理员白名单内的 QQ 可发送 `@用户 踢` 或 `@用户 踢了` 直接踢出成员，也可以一次 @ 多个用户批量踢出；当前群踢出成功后，会通过 `get_group_list` 获取机器人所在群，再用 `get_group_member_info` 检查该用户是否在其它群，存在则一并踢出。发送 `@用户 踢` 或 `@用户 踢了` 时，还会拉取该用户最近消息并最多撤回 50 条；多个 @ 用户会逐个处理，50 条按每个目标用户单独计算。发送 `开启禁言` / `关闭禁言` 会调用 OneBot `set_group_whole_ban` 开关当前群全员禁言，发送 `开启全部禁言` / `关闭全部禁言` 会先调用 `get_group_list` 获取机器人所在群，再逐群开关全员禁言。

会触发：`123456789`、`你好1078887813`、`你好A1078887813 你好`

不会触发：`12345678`、`1234567890123`、`107888A7813`、`123 456 789`、包含 `http://` 或 `https://` 的链接消息

</details>

每天可免费使用对应次数，不按群区分，换群不会重置次数；小说下载开始提示会在 `正在下载中请稍等.....` 下方显示剩余免费本数，最后一本会提示可购买 VIP 无限下载，次数用完后回复当日免费次数已下载完并分行提示看群公告或第二天继续免费下载。设置为 `0` 时不开放免费额度。管理员不受激活门禁和免费额度限制。用户激活、卡密、每日免费额度、全局/群聊/私聊付费开关状态、番茄 API `mantou_runtime_state`。

群文件清理管理员白名单内的 QQ 还可发送 `开启私聊收费` / `关闭私聊收费` 或 `开启私聊付费` / `关闭私聊付费` 控制私聊激活门禁，默认开启；私聊开关状态写入 MySQL `mantou_runtime_state`，不会影响任何群聊。全局收费关闭时，群聊和私聊独立开关已设置则按独立开关判断，未设置则免费；全局收费开启时强制群聊和私聊全部进入收费判断；未设置全局总开关时才按当前群聊或私聊独立开关判断。群聊和私聊下载入口共用同一套激活拦截判断：群聊读取当前群开关，私聊读取私聊开关。

群文件清理管理员白名单内的 QQ 可发送 `状态` 查看系统信息、运行内存、运行 CPU、系统内存、系统 CPU、系统运行时间、插件运行时间、插件版本、番茄/七猫开关、当前番茄 API、全局收费、当前群收费、私聊收费、每日免费额度、数据库配置状态和 UC/百度网盘启用状态。状态命令不会显示 OIAPI key 或网盘 Cookie 原文。

群文件清理管理员白名单内的 QQ 可发送 `帮助` 查看 `主动触发` / `被动触发` 大类，随后在 120 秒内发送数字进入小类，再发送数字查看触发指令列表，再发送数字查看详情；发送 `0` 返回上一层。也可直接发送 `帮助 1` 查看指定大类。普通成员无法触发帮助功能。

群文件清理管理员白名单内的 QQ 可发送 `开启番茄` / `关闭番茄` 和 `开启七猫` / `关闭七猫` 开关对应小说下载功能，状态写入 MySQL 的 `mantou_runtime_state` 表，重载后继续生效。关闭后用户发送对应小说链接会直接回复该功能已关闭，不进入下载流程。

插件配置里填写 `uc_pan_cookie` 后，番茄和七猫小说下载完成会先把完整原小说 txt 上传到 UC 网盘，上传目录读取 `uc_pan_upload_dir`，默认 `/小说机器人`。上传前会分页扫描并删除目标目录下与原小说文件名完全相同的远端普通文件，不删除同名文件夹；如果创建上传目录时返回同名冲突，会重新查找已有目录继续上传；如果 UC 上传仍返回同名冲突，插件会重新扫描并删除同名旧文件，再继续使用原小说文件名重试，不再改用备用远端文件名；如果上传完成接口返回 `23008` / `file is doloading`，插件会复用预上传阶段返回的文件 ID 继续创建分享，创建分享时文件仍在处理中也会等待重试。UC 上传成功后，QQ 收到的仍是和原小说同名的 txt 文件，但文件内容只有 `请复制链接打开UC网盘` 和 `链接：xxx`；UC 上传失败时会回退发送完整原小说 txt。`uc_pan_cookie` 留空时保持原来的 QQ 文件发送方式。

插件配置里填写 `baidu_pan_cookie` 后，番茄和七猫小说生成完整原小说 txt 后会后台上传到百度网盘，上传目录读取 `baidu_pan_upload_dir`，默认 `/小说机器人`。如果目录不存在会自动逐级创建；完结小说在目标目录已有同名普通文件时会直接跳过重复上传，连载小说仍会删除目标目录下同名普通文件后重新上传，不删除同名文件夹。`baidu_pan_upload_status` 控制上传书籍状态，可选择 `完结`、`连载` 或 `全部`，默认只上传完结。百度网盘只做后台备份，不创建分享链接、不生成链接 txt，也不影响 QQ 原有发送逻辑；如果 UC 网盘也启用，会先按 UC 逻辑决定 QQ 发送内容，再上传原小说到百度网盘。

群文件清理统一走 QQ 群文件网页接口 `pan.qun.qq.com/cgi-bin/group_file/get_file_list` 和 `delete_file`，不再使用 OneBot 适配器扩展接口，也不连接 NapCat 或 NapCat WebUI。管理员需先发送 `登录群文件` 获取登录链接，在浏览器登录后复制 Cookie，发送 `群文件登录cookie <cookie>` 保存；Cookie 存 MySQL `mantou_runtime_state`（namespace=`web_group_file_cookie`，state_key=管理员QQ），按管理员 QQ 隔离，31 天有效，过期自动清空，重载后继续生效，不暴露到 `状态` 命令。发送 `清理群文件` / `群文件清理` 时，插件列出「添加群聊」里的目标群列表，同一会话同一发送者 120 秒内发送编号清理对应群，发送 `0` 取消；列表为空时会提示先发送 `添加群聊 群号` 添加目标群。发送 `清理全部群文件` 会先发送 `正在清理群文件（全部）`，再读取「添加群聊」添加的目标群列表，复用同一个 aiohttp session 逐群走网页接口清理，并汇总成功/失败的群数与文件数。群聊管理指令 `添加群聊 群号 [群号...]`、`删除群聊 群号 [群号...]`、`查看群聊` 仅群文件清理管理员白名单 QQ 可用，群号列表写入 MySQL `mantou_runtime_state`（namespace=`cleanup_groups`），重载后继续生效。网页接口从 Cookie 提取 `skey` 后用 hash 算法计算 `bkn` 鉴权，文件列表每页 50 个并发拉取，删除每批 20 个并发提交，失败自动重试 3 次；当前实现只删根目录文件，不递归子文件夹；遇到 `ec != 0` 或 HTTP 非 200 时按接口错误提示重新登录。

七猫小说下载完成后会临时写入 `功能文件/下载缓存/`，UC 网盘未启用或上传失败时优先通过 AstrBot `File` 组件上传到 QQ，无法使用时再回退 OneBot 本地路径上传。通过 `File` 组件发送时会延迟清理缓存，避免适配器读取前文件被删除；OneBot 回退上传尝试结束后立即删除 txt 文件。发送文件名格式为 `[完结]书名：xxx 作者：xxx.txt` 或 `[连载]书名：xxx 作者：xxx.txt`。txt 文件顶部会写入免责声明，文件发送成功后不再额外发送完成提示，只有发送失败时回复错误原因。

番茄小说识别 `fanqienovel.com`、`changdunovel.com`、`fqnovel.com` 和 `novelfm.com` 链接，支持 `changdunovel.com/t/短码` 分享短链和 JSON 卡片中的链接。下载前会先回复书名、作者、状态、章节、字数和 `正在下载中请稍等.....`，外部提示不显示简介，txt 文件头部会保留简介。群文件清理管理员白名单内的 QQ 发送 `查看API` 会列出番茄小说下载 API，随后发送 `1` 切换到 OIAPI，发送 `2` 切换到析API，发送 `3` 切换到崩溃API，发送 `4` 切换到聚合API，发送 `5` 切换到 Y6api；也可直接发送 `oiapi`/`析api`/`崩溃api`/`聚合api`/`y6api` 快速切换。当前选择会写入 MySQL 的 `mantou_runtime_state` 表，重载后继续生效。五个接口不会自动互相切换；OIAPI 返回业务失败时只显示接口 `message` 内容，例如 `付费内容不解析` 或 `key额度不足`；正文批次请求只要报错会立即停止当前下载，不再拆分，也不继续请求后续批次；仅当 OIAPI 返回 `请检测章节选择是否正确` 时，会额外请求一次 OIAPI `method=chapters` 目录，并按 OIAPI 返回的章节数量单次重试正文请求，第二次仍失败就停止，避免继续消耗 key 额度。选择析API时，书籍详情仍优先使用番茄官方落地页和官网页面接口，目录和正文使用析API。选择崩溃API时，会调用 `http://111.170.14.45:2000` 创建下载任务，轮询进度接口并下载完整 TXT，再重新整理为现有番茄 TXT 格式。选择聚合API时，会调用 `http://101.35.133.34:5000` 的 `/api/detail`、`/api/book`、`/api/directory` 和 `/api/content?tab=批量`，正文按每批 50 章、最多 10 个批次并发下载，独立模块位于 `功能文件/API功能/聚合API/番茄小说.py`。选择 Y6api 时，会调用 `https://y68-napi.hf.space` 的 `/api/detail`、`/api/directory` 和 `/api/download` 后端打包下载接口，下载到的整本 TXT 会重新解析为简介和章节正文，再交给统一 TXT 构建函数输出 OIAPI 一致的文件头部，独立模块位于 `功能文件/API功能/Y6api/番茄小说.py`。析API、聚合API和 Y6api 正文会保留段落换行，所有API最终 txt 都统一使用 CRLF 换行。文件写入 `功能文件/下载缓存/`，UC 网盘未启用或上传失败时优先使用 AstrBot `File` 组件发送；无法使用时再尝试裸本地路径和 `file://` URI 的 OneBot 上传接口。通过 `File` 组件发送时会延迟清理缓存，OneBot 回退上传尝试结束后删除缓存 txt，成功时不额外发送完成提示。

QQ 官方机器人 `qq_official` 发送文件应优先走 AstrBot `File` 组件，它会封装官方富媒体接口并发送 `media` 消息；如果 QQ 官方群聊返回 `call inner proxy error`，这是平台富媒体上传限制或临时错误。OneBot 的 `upload_group_file`/`upload_private_file` 只适用于 OneBot 适配器回退。

群文件清理管理员白名单内的 QQ 发送 `授权` 会生成 `https://club.vip.qq.com/transfer?open_kuikly_info=...` 授权链接；如果当前适配器取不到数字群号，可以发送 `授权 数字群号` 手动指定 `groupCode`；如果也取不到机器人 QQ，可以发送 `授权 数字群号 机器人QQ` 手动指定 `botUin`。插件会动态获取当前群号和机器人 QQ 号，机器人 QQ 会优先读取 AstrBot `context.robot_id`，并会递归读取事件 JSON、消息段 JSON 和 URL 编码 JSON 中的 `groupCode`、`botUin`、`botUid` 等字段；如果适配器不支持 UID 转换，会明确回复缺少机器人 UID。触发授权命令时会输出一条受控诊断日志 `授权链接事件诊断`，UID 转换接口有返回但无法识别时会输出 `授权链接UID转换响应未识别`。链接必须由群主在安卓/鸿蒙 QQ 9.2.90 及以上打开，iOS 暂不支持。
