# 馒头bot

适用于 AstrBot **QQ 官方机器人**的小说下载、网盘分享与群聊管理插件，提供独立网页控制台和 QQ 阅读开放 API。

## 主要功能

- **小说下载与找书**：识别平台分享链接和卡片，支持按书名、作者聚合搜索，生成 TXT。
- **小说交付**：UC、夸克、百度多账号分享；每群独立选择网盘账号，也可只对某个群关闭网盘、直接发送文件。
- **网页控制台**：管理多个机器人、阅读账号、网盘、小说开关、消息记录及群设置，支持手机和浅深主题；登录、控制台和桌面聊天页共用顶栏与完整导航侧栏，采用暖白/深暖灰表面、细边框与竹青控件，消息发送、引用、附件和浮层同步主题。手机聊天页按 QQ 参考采用紧凑顶栏、灰底白气泡、输入框与蓝色发送同行、附件工具下置，并适配深色主题。
- **群聊管理**：按群开启广告拦截，提供撤回、禁言、移除成员和黑名单管理，以及入群欢迎、使用教程。
- **聊天媒体保存**：接收和成功发送的图片、文件、音频、视频自动保存到自建图床；网页优先读取已保存文件，原 QQ 附件地址保留。
- **QQ 阅读开放 API**：独立多 Key，支持整本、单章、多章和多本批量下载，无需 AppID。

插件不设激活、卡密、收费或每日免费次数。平台可读范围仍以接口、账号权限和实际返回为准，不保证付费、锁定或尚未发布的正文可下载。

书旗 XML 目录仅在返回有效非负 `TotalCount` 时核对条目数量；缺失计数不作数量不一致告警。接口未提供任何有效章节时仍停止下载，不生成空文件。

番茄正文补拉按分组和章节保存成功结果，缺章或正文格式异常仅追加一轮失败章节补拉；每轮请求的超时、连接异常和408/指定5xx最多额外尝试一次，明确业务拒绝、403、429不自动重放。日志分别显示已处理、成功和失败数量，并记录受控失败阶段与数字状态。最终仍缺章时停止整本交付，不生成缺章占位文件。

**聊天日志防护**：插件运行期间，AstrBot 核心接收消息的日志摘要如包含连续超过 8 个组合符号，或同一组合符号连续超过 3 次，仅显示有界前缀及“异常叠加字符消息已隐藏”提示。正常多语言文字照常输出；收到的事件、指令解析和消息记录原文不变，不自动撤回或处罚发送者。

## 安装与更新

1. 在 AstrBot WebUI 的插件管理中，用下面的仓库地址安装：

   ```text
   https://github.com/TimShitPig/mantou_Bot
   ```

2. 确认依赖已安装，完整依赖以 [requirements.txt](requirements.txt) 为准。主要包含 `aiohttp`、`httpx[http2]`、PyCryptodome、`gmpy2`、NumPy、`loky` 和 PyMySQL。
3. 配置 QQ 官方机器人、插件管理员、数据库和网页登录密码；需要网盘分享时再添加网盘账号。
4. 在插件管理中选择“管理 → 重载插件”，确认日志显示本次安装版本。

后续通过 GitHub 更新或重新安装。**重新安装前先等待当前上传结束**：缓存位于项目内部，替换插件目录可能删除未完成任务的文件。

已使用 Git 安装时，也可在实际插件目录执行 `git pull` 后重载。重载只读取服务器当前磁盘代码，不会自动拉取 GitHub；日志版本或行号未变化时，应先确认安装目录与代码，再考虑重启 AstrBot 容器。私有仓库需要有权限的 Git 凭据或 Deploy Key。

## 首次配置

AstrBot 插件配置页仅显示启动所需的 **9 项**：插件管理员、网页端口与登录账号/密码、MySQL 地址/端口/用户名/数据库名/密码。

其余设置登录插件网页后台后管理：

| 后台入口 | 设置内容 |
| --- | --- |
| 系统设置 | 网页监听地址、外网地址、登录信息、数据库 TLS/CA/超时等连接设置 |
| 机器人配置 → 基础设置 | 当前机器人的管理员名单、教程图片宽度与自建图床 API Token；密码只写入、不回显，留空保留原值，保存后生效 |
| 机器人配置 → ZLibrary | 账号导入与分组管理、邮箱 API Key 和注册 rx；注册设置独立保存，Key 留空保持原值 |
| 网盘配置 | UC、夸克、百度账号、上传目录、默认账号及启停 |
| QQ 阅读账号 | Cookie、手机号/扫码登录、账号选择和会员资料 |
| 晋江账号 | 晋江 App 扫码、Token/读者编号添加、多账号选择、启停及资料刷新 |
| 机器人配置 → QQ 阅读 → 开放接口 | 服务公共开关、随机生成与撤销多个 Key |
| 消息记录 → 群菜单 | 当前群的网盘账号、文件直发和群管理 |

[_conf_schema.json](_conf_schema.json) 仍保留隐藏字段及默认值，避免升级或保存配置时丢失已有账号、Key 和 `bot_profiles` 机器人配置；隐藏不代表删除数据。无需手动编辑这些内部字段。

**数据库**：运行状态、账号与聊天记录使用 MySQL。数据库名留空时使用用户名；默认端口 3306、连接超时 10 秒。TLS 默认 `preferred`，也可选 `required`、`verify_identity`、`disabled`，认证或 TLS 失败不自动降级。系统设置可测试未保存表单，仅执行查询，不保存或建表；密码留空表示不修改，保存连接配置后重载生效。未配置数据库时不反复尝试连接，小说默认开启，主网盘默认 UC，账号、开关与历史不能获得完整持久化能力。

**网页**：默认监听 `0.0.0.0:8090`，自动生成服务器 IPv4 访问地址；Docker 需映射端口。配置管理员登录密码后访问 `http://服务器IP:8090`，也可填写完整 HTTP/HTTPS 外网地址供域名或反向代理使用。教程配图改用自建图床的固定公开链接，无需转发图片路径；图片宽度默认 480，允许 160～1080。

**自建图床**：图片、文件、音频、视频的接收和成功发送都会安排保存到 `https://mantou-imgbed.pages.dev`；网页本地图文图片已上传的结果直接复用。请在登录保护的“机器人配置 → 基础设置 → 自建图床 API Token”填写图床生成的 Token。Token 按机器人独立保存在已有 `bot_profiles` 自由配置中，只写入、不回显，留空保留原值；不新增 `_conf_schema.json` 配置项，不写入源码。四张教程图片和现有链接继续保留。

**多机器人**：登录后先选择机器人。列表先显示本地机器人资料，QQ 昵称、头像和历史统计在后台补齐；点选后先打开工作台，再显示已加载的数据。管理员、小说开关、测试模式、网盘账号与群选择、QQ 阅读与晋江账号、广告开关和布局按认证 AppID 隔离；数据库、网页监听、网页登录和开放 API Key 为服务公共设置。聊天列表、历史及群状态还按聊天类型、会话编号隔离。“退出机器人”返回选择页，“退出登录”结束管理员会话；停用机器人可配置，但不能借用其他机器人发送消息。

## 常用指令

直接发送支持平台的分享链接或卡片即可下载。找书结果每页顶部显示查询关键词，书目之间有短分隔线。每本两行，显示“书名：作品名”和“作者：作者名 · 平台 · 完结/连载”，未取得状态时显示“未知”。直接发送编号即可下载。点击书名或整段“作者名 · 平台 · 状态”会填入同一本书的选书指令，发送后下载；点击翻页按钮则直接翻页。

| 使用者 | 指令 | 作用 |
| --- | --- | --- |
| 所有人 | `番茄找关键词` / `七猫找关键词` / `QQ阅读找关键词` / `QQ浏览器找关键词` / `书旗找关键词` / `得间找关键词` / `西瓜找关键词` 等 | 仅搜索指定平台；支持平台名后加“小说”、空格及 QQ 大小写，沿用翻页和选书 |
| 所有人 | `找关键词` / `找书 关键词` / `找书名 关键词` / `找作者 关键词` | 聚合找书，支持书名、作者及组合查询，例如 `找仙逆作者耳根`、`找仙逆耳根`；精确命中优先，模糊匹配仅保留相关结果；每页 5 条；本人点击按钮或发送上一页/下一页翻页；编号跨页连续，直接发送 `1`、`2` 等编号下载，也可发送 `选1` 或 `选一` |
| 所有人 | `帮助`；群内单独 @机器人 | 公开菜单、小说列表、使用教程、添加机器人 |
| 插件管理员 | `帮助` / `状态` | 管理菜单与系统运行状态 |
| 插件管理员 | `小说` / `小说列表`、`开小说` / `关小说`、`开平台名` / `关平台名` | 查看状态、控制当前机器人的总开关或单平台开关 |
| 插件管理员 | `开测试` / `关测试` | 管理员可测试关闭的平台，普通用户仍受开关限制 |
| 插件管理员 | `网盘` / `网盘状态` / `当前网盘`、`换UC` / `换夸克` / `换百度` | 查看或切换当前机器人的默认分享网盘 |
| 插件管理员 | `UC换N` / `夸换N` / `夸克换N` / `百换N` / `百度换N` | 切换当前群对应网盘的账号 |
| 插件管理员 | `关网盘` / `开网盘` | 仅当前群改为文件直发 / 恢复默认网盘 |
| 插件管理员 | `夸克登录` / `添加夸克` / `夸克账号` / `删夸克N` | 扫码、添加说明、账号查询及删除；按指令支持的私聊入口使用 |
| 插件管理员 | `开广告` / `关广告` / `广告状态` | 当前群广告拦截，默认关闭 |
| 插件管理员 | `禁言 @成员` / `禁 @成员 1` / `解除禁言 @成员` / `解 @成员` | 默认 7 天，裸数字按天，支持秒、分、时、天 |
| 插件管理员 | `@成员甲 @成员乙 踢` / `踢 @成员` / `踢了 @成员` | 从 QQ 提及列表选择成员，去重后每次最多 20 人，仅移出当前群 |
| 插件管理员 | `测试账号` / `注册ZLibrary` / `创建ZLibrary账号` | 账号准备；“测试账号”每次独立创建新账号，其余入口优先复用 |

如果 QQ 机器人只接收群内提及消息，请同时 @机器人，例如 `@机器人 @成员甲 @成员乙 踢`。

白名单外的管理指令静默忽略。管理员也可粘贴 UC、夸克、百度或 QQ 阅读 Cookie；QQ 阅读另支持网页手机号验证码和 QQ 扫码登录，多账号可选择、启停、刷新会员资料。账号失效后，点击原账号卡片上的“重新登录”即可更新登录状态。凭据不在普通列表中回显，QQ 阅读密钥仅在登录后主动点击“显示”时按需读取。截图或短暂切到后台时，QQ 阅读扫码弹窗保留当前二维码，回到页面后继续查询扫码状态。

含分享链接的输入先走链接识别，不会把 URL 参数当作书名送去搜索。找书先按完整书名/作者、明确版本与卷册、前缀、包含、整书名容错和部分关键词匹配排序；同人、续写不再冒充原书版本，明确搜索同人时仍可正常找到。书名兼容中文与阿拉伯数字，例如 `找斗罗大陆三龙王传说` 和 `找斗罗大陆3龙王传说` 可互相匹配并分别显示；至少三字的标题支持一处错字、缺字或相邻字颠倒，准确结果优先。长书名还支持部分关键词召回：例如 `都说师傅是好人` 可以找到标题含“师傅”或“好人”的相关书籍；中文至少命中连续两个实字，英文按完整单词匹配，仅有“我、是、的”等虚词或无关推荐不展示。支持书名和作者组合，例如 `找 龙族 江南`；多个词须全部匹配，可换词序。全角英数与大小写统一处理，作者不做数字换写。

书名查询即使已有精确结果，也会在预算内用数字换写和首轮候选实际命中的有效词片段补搜，未取得有效片段时沿用前后片段，最多三个补搜词；补搜结果仍按原查询的完整匹配、整书名容错、部分关键词分层排序；多平台首轮搜索及目录校验限时十二秒，补搜共用八秒总预算，按平台串行查询、跨平台流水执行，不再按词平分等待时间。各平台独立搜索和校验，截止时汇总已完成的结果；QQ阅读先筛选完整原词相关候选再检查目录与免费章节，详情和目录不请求正文密钥池，酷匠原查询与补搜复用同一会话。目录预检只回收未完成的检查，已核验的书籍继续展示。单独查询 ZLibrary 保留最长 330 秒的首轮搜索时间。指定平台只在该平台补搜，关闭的平台不请求；请求失败的平台当次不继续换词。

普通找书同时保留包含完整关键词的书名和匹配的作者作品。找书结果先过滤无关书籍，再按平台优先级分组显示，QQ阅读排在QQ浏览器前面；同一平台内按相关程度排序，原始排名、同书共识和热度作为后续参考。同书在QQ阅读和QQ浏览器均有可用结果时优先显示QQ阅读。只合并显示书名相同且作者相同的记录，数字写法或文字不同的标题分别保留；番茄作者卡片、系列分组中的书籍全部展开。找书会话按机器人、会话和用户隔离。每次翻页或选书后重新计时，闲置 10 分钟清除；同一会话重新找书时替换上一份结果。翻页回调仅携带“上一页/下一页”，不生成随机会话 ID，始终操作当前用户最新一份结果。私聊翻页按钮使用单聊内可点击权限，仍按机器人和当前用户读取独立结果；群聊按钮继续只允许当前查询成员点击。首页/末页隐藏无效方向，单页不显示按钮；番茄、米读及百度、小米、酷匠仅对当前页状态未知的条目限时补查同书详情，核对书号、书名和作者后回填；百度、小米、酷匠共用最多4路及2.5秒总预算，同平台复用会话，不请求目录。塔读按实际 isSerial 字段识别连载/完结，平台没有明确状态时保留未知。

## 支持的小说平台

| 平台 | 入口与关键说明 |
| --- | --- |
| 番茄 | 书籍链接、分享卡片和短篇；搜索页链接需先选具体书籍。缺失状态、字数时补查同书目录及经同版本核验的官方关联小说资料，取不到有效数据时保留未知，提示格式不变 |
| 七猫 | 长篇/短篇链接、分享卡片；纯图片版提示无文字正文 |
| 书旗 | 官网、分享短链、章节链接和卡片；每本复用一个异步 HTTP 会话，正文最多 200 路并发；目录数不一致或部分章节失败时，保留可获取正文；上游 UTF-8 字节损坏单独记录，不替换或忽略损坏字节 |
| 追书 | 追书神器链接及分享卡片，与疯狂追书分别处理；同本书复用一个异步 HTTP 会话，正文和 PyCryptodome 库解密各最多 300 路，不足时按实际章数；取消时等待请求及解密收尾 |
| QQ阅读 | `reader.qq.com`、`book.qq.com`；账号会员状态、免费边界与目录共同决定可读范围 |
| QQ浏览器 | 分享链接、`qb://ext/novelreader`；空书号卡片可按书名精确回搜 |
| 得间、点众、塔读 | 对应平台书籍链接和分享卡片 |
| 百度 | 官方分享链接；下载可完整公开读取的章节，详情和 TXT 按实际取得的章数显示 |

- 修为、背包的身份与资料读取并行且每次实时校验；修为查询的身份和页面请求遇到瞬时超时或断流各最多重试一次，仍分别共用原30秒和60秒总时限，认证、验证码、HTTP拒绝及解析错误不重试；连续查询复用连接，账号 Cookie 仍独立。后台每分钟资料刷新独立于挂时长开关，查询不占账号锁等待网络，回填先核对账号代次、身份和原 Cookie；控制台操作直接返回同次摘要，避免查询完成后再次排队。领取、突破及使用物品仍串行提交。
- 日志记录登录/注册、开关变更、在线心跳、正文读取、奖励检查/领取、修为及背包操作的阶段和结果；奖励最终确认入包后显示中文物品名及有效等级，数量仅在实际返回时显示。未领取时区分已核实的奖励失效、未拾得物品和服务拒绝；预览物品不记为已领取，不记录密码、Cookie、签名或响应原文。插件热重载先停止任务并保存进度，再按保存开关恢复当前章节剩余停留及已读记录；不恢复旧会话的奖励通知或补发在途领取，结果未知时继续保持领奖关闭。新版启动等待旧版完整停止，正确识别 AstrBot 原始配置及机器人独立配置，按保存开关自动恢复 STV，并在平台延迟加载后补启动；重复启动保留健康任务，不重置当前章节的剩余停留。

## 网盘、直发与缓存

### 小说交付

- 每次下载只用**一个**选定网盘；优先使用当前群覆盖，其次兼容旧群账号选择，再使用默认网盘及默认启用账号。百度不作为后台备份。
- 网页当前群“⋮ → 网盘账号”可选择账号或“关闭网盘，直接发送文件”。此设置只影响该群，不影响其他群、聊天媒体或开放 API。
- 文件直发先发原 TXT；官方完整响应明确拒绝后才尝试一次 ZIP，包内保留原文件名和原始正文。认证/权限拒绝、限流、超时或结果不明不自动改发，避免重复提交。
- 网盘成功后发送该平台的分享链接与“打开”按钮；失败只给固定短提示。后台区分正文、文件生成、上传和发送阶段，持续失败的上传文件由续传资料保护。

### 文件位置与清理

所有新缓存统一写入项目内 **`功能文件/文件缓存/`**，按小说、媒体、临时、消息记录和其他缓存分类，不再在项目外创建 `mantou_bot_file_cache/`。旧外部缓存兼容迁移，活动任务暂留原路径；不要手动删除正在使用的 TXT、`.uploading` 或 `.upload_jobs`。

UC、夸克、百度以配置目录为总目录，小说上传进入 `总目录/YYYY年M月D日/`。本地小说缓存每天服务器本地零点清理前两天及更早的 TXT，保留今天、昨天和活动/待续传文件；启动/重载也清理无占用残留。远端仅 UC、百度按上述日期规则清理旧小说和已确认空的过期日期目录；夸克不自动清理远端文件或目录。

夸克小说直接上传到当天目录，不扫描或删除同名书籍；分享只使用本次上传返回的文件 ID，不按同名旧文件匹配。 同账号最多8个文件并发上传，同名上传与分享仍串行；目标目录成功解析后按账号缓存5分钟，API与OSS跨文件复用连接，Cookie保持客户端独立。空闲连接30秒后回收，停止或重载不关闭仍被在途任务使用的连接。

夸克目录、上传、分享、下载和账号权益使用 App 移动网关，现有 Cookie 和扫码换票继续兼容。小于等于2 MiB的文件采用 App std 单片流程，预上传直接携带哈希，随后签名上传并完成确认；较大文件沿用已验证的 OSS 流程。App 的多文件上传为逐文件排队，`getUploadUrls` 是单文件分片签名接口，不是一次请求上传多个文件。

夸克 OSS 分片对 408/429/500/502/503/504、断流、超时最多尝试三次，每次重开文件、刷新签名；只重试同一上传 ID 和分片号，不盲目重放预上传、合并、完成或创建分享。权限/签名拒绝不循环重试。上传授权在同一任务内对瞬时网络错误及上述 HTTP 状态最多尝试三次，单次限时45秒并递增退避；失败日志只显示阶段和分类，持续失败沿用TXT续传保护。

### 聊天媒体

每个文件在首次开始上传时按服务器本地日期归入 `聊天媒体/YYYY年M月D日/图片`、`文件`、`音频` 或 `视频`，同一天共用日期目录。保留原字节、动画、原文件名及原附件索引，不转码；实际最多8路。客户端单文件上限800MiB，超过16MiB使用16MiB分片；网页发送本身仍沿用图片10MiB、其他媒体256MiB的现有限制。大文件实际能否完成还取决于图床平台配额。

保存状态与已确认图床地址写入 MySQL，网页显示“保存中”“已保存到图床”等状态，并优先从图床读取。启动会恢复已有待保存任务；已确认分片从下一片继续，上传结果不明时不自动重传。拿到地址后写库失败只重试保存结果。失败或待确认的本地副本放在项目 `文件缓存/临时缓存/图床待保存/`，避免普通临时清理误删；成功后清理副本。仅浏览器持有、服务器没有原字节或可读 URL 的旧附件需等待可读来源；未保存前原 QQ 地址已过期的内容不能凭空恢复。图床服务端分片内部有固定重试，插件不额外重放已提交请求。旧夸克、蓝奏云图床和远端历史文件不参与本流程。

## 网页消息记录与群管理

在群聊中右键普通成员的消息或头像，选择「踢出用户」并确认，即可请求将该成员移出当前群。机器人须拥有 QQ 官方的成员移除权限。

打开会话时优先加载最近 16 条消息。鼠标停留或键盘聚焦会话时，可提前读取一个会话的首屏，打开时复用。有本页缓存时先显示缓存，再用最新消息校准。会话列表滚动会复用仍在视野里的头像。最新消息显示后，后台提前准备相邻的历史消息。连续滚动优先使用已取回的记录，反向滚动优先复用刚卸载的消息。滚动到距历史窗口边缘约三屏时补入相邻消息。普通历史窗口按消息实际高度估算，以约九屏为目标，最多保留 96 条活动历史；翻页时优先保留当前可见行，并卸载远处的记录。滚动条按当前窗口的高度自然变化。向反方向滚动可重新加载，翻页时保持当前消息的位置。快速反向滚动时，当前分页结束后会自动处理排队的方向。临时请求失败且仍停在同一侧时，自动重试最多两次。聊天正文右侧的细滚动条在滚动、鼠标悬停或键盘聚焦时显示，可直接拖动滑块。向上翻阅时，聊天区顶部显示当前可见消息的日期，停下后自动淡出，向下滚动时隐藏。群广告拦截与网盘选择在打开右上角菜单时加载，纯文字聊天在完成滚动定位后立即显示。

- 登录后管理当前机器人：收发消息、查看历史/原始数据、引用定位、搜索提及、附件、备注和群设置。消息右键/长按提供复制、引用、撤回等操作，键盘支持 Shift+F10；切群或切机器人废弃旧响应。
- 私聊昵称直接读取当前 QQ 消息作者的名字，收到新昵称时同步更新列表和标题；不再从保存昵称或关联群记录匹配。手工备注优先，头像独立保留，明确提供非空但不可见的名字（如 `U+007F`）时按空白昵称显示，覆盖旧昵称；只有缺字段、null 或空串才保留当前已取得的名字或显示占位，旧缓存和历史结果不会补回旧名。
- 控制台手动刷新私聊资料时，使用当前机器人的认证和用户 OpenID 直接调用 QQ 官方用户基本信息接口，补齐昵称和头像；只有好友通知、尚未收到普通私聊时也可获取。私聊事件中已有的昵称与明确空白优先，查询失败保留原资料。群聊消息优先显示 QQ 下发的群内昵称和头像，旧消息沿用已有显示资料。
- 新好友添加机器人时，事件缺少昵称会自动向 QQ 查询。打开仍缺名的已有好友私聊时也会尝试补齐，查询成功后更新会话列表和聊天标题。人工备注与事件中的昵称优先。
- 通过插件群管理批量移除成员后，聊天区会在同一条系统通知中显示机器人移除的成员名单。同一秒内相邻的普通离群通知会按名单合并显示。
- 聊天右上角的「显示撤回」可查看当前会话的已撤回消息，向上滚动可查看更早记录，再点一次恢复全部消息。切换会话后默认显示全部消息。
- 引用、附件和草稿都放在聊天输入框里。可点卡片上的「×」单独移除，或使用键盘删除。群聊引用自动带上 @ 时，第一次退格只删除 @，再按一次删除引用。全选后可一并清空。
- 聊天三栏可拖动尺寸并按机器人保存，支持浅深主题、手机布局、回到底部及引用后返回最新消息。群角色未知时不据展示标签推断权限。
- 消息 ID 完整保存且最多512字符，不截断、不将对象转换为编号。无效或超长ID拒绝落库并结束该项重试，不阻塞后续消息；后端只记录数量、长度和上限，数据库断连等故障仍保留重试。
- 群移除状态保留官方 `GROUP_DEL_ROBOT` 原始事件的 `dismiss`：明确 `true` 显示“群已解散”，明确 `false` 显示“你已被移除群聊（非群解散）”，缺失或类型不正确仍显示通用移除提示。只使用该事件的有效群标识与机器人 AppID，标识缺失只记录受控诊断，不猜测群聊；重新加入或收到新群消息后恢复正常显示，历史记录保留。
- MySQL 历史不按条数或时间自动删除；内存和网页分页上限不等于保存上限。手动清理或删除会话先预览再确认，保留预览后的新消息，不撤回 QQ 消息、不删除群资料或网盘文件。
- 广告拦截仅当前群生效，默认关闭。群主、群管理员和普通 @消息放行；普通成员命中数字/卡片等规则后，最多联动撤回本群该用户截至触发消息的 30 条已记录消息。自动拦截不会踢人，禁言次数可跨群累计，处罚只作用当前群。
- 撤回是否成功、权限和时限均以 QQ 官方响应为准；不将入退群系统通知编号当成消息 ID，不宣称突破平台时限。群成员/黑名单操作每次最多 20 人，写请求不盲目重放。
- 群状态、资料、人数与好友关系根据可信事件和接口结果更新，保留历史；陌生昵称和身份关联不按名字、头像或相邻消息猜测。

## QQ 阅读开放 API

在插件网页后台的“机器人配置 → QQ 阅读”分区开启开放接口，点击“保存设置”生效。点击“生成 Key”立即添加，列表按标识逐个撤销；新 Key 只展示一次，已有 Key 不回显。需要替换全部 Key 时展开“批量替换 Key”，每行填写一个后保存，留空保持当前列表。服务复用帮助网页地址，前缀为 **`/openapi/qq-reader/v1`**。

浏览器可直接访问以下入口，示例需替换地址、Key 和书籍 ID：

```text
http://服务器IP:8090/openapi/qq-reader/v1/download?key=你的Key&book_id=书籍ID
http://服务器IP:8090/openapi/qq-reader/v1/chapter?key=你的Key&book_id=书籍ID&chapter=1
http://服务器IP:8090/openapi/qq-reader/v1/chapters?key=你的Key&book_id=书籍ID&chapter_range=1-1000
```

整本返回 UTF-8 TXT，单章和多章直接返回带原目录序号、标题、正文的 JSON，不创建网页。章节参数用完整目录的 **1 起始序号**，无需章节 ID；支持 `1-n`、`101-n` 和数字终点，终点超过现有目录取到末章，起点超出则失败，不等待虚构章节。

程序调用使用 `Authorization: Bearer <API_KEY>`，无需 AppID 或控制台 Cookie：

| 方法与路径（相对前缀） | 请求或返回 |
| --- | --- |
| `POST /tasks` | `{"book_id":"123456","chapter_range":"1-n"}` |
| `POST /tasks/batch` | `{"book_ids":["123456","234567"],"chapter_range":"1-n"}`；也支持单个 `book_id` |
| `GET /tasks/{task_id}` | 查询任务状态 |
| `GET /tasks/{task_id}/file` | 用同一 Key 获取成功任务的 TXT |

仅上述三个浏览器 GET 入口接受 URL `key`，其他接口仍须 Bearer。不同 Key 的任务隔离；撤销 Key 会结束相关等待。未限制批量书籍/排队数量，固定两路下载，正文超时 30 分钟，单文件上限 64 MiB，结果保留 1 小时。

账号识别以**实际选中的 QQ 阅读账号**为准：只有一个机器人选中账号时可复用，即使配置了多个机器人；没有选中账号或多个机器人均选中账号时匿名，不借用首实例。每批固定账号，复用任务同时校验账号、章节范围和结果格式，登录后不复用旧匿名结果。API 不发送 QQ 消息或上传网盘；同进程重载保留任务，进程重启需重新提交。

## 排错与维护

| 现象 | 核对方式 |
| --- | --- |
| GitHub 已更新但仍是旧行为 | 检查实际插件目录和启动版本；拉取/重装之后再重载，必要时重启容器 |
| `rate_limit_check.stage`、会话被暂停 | AstrBot 核心限流；检查当前平台实际使用的 `platform_settings.rate_limit`，`stall` 等待、`discard` 丢弃 |
| 群资料刷新受限 | `bot_state`、`info` 各 30 次/分钟，按 AppID/接口共享；强制刷新不绕过配额和失败冷却 |
| 群状态被标记已移除 | 可信退群事件，或 HTTP400/SDK 缺失 HTTP 时完整码对 `11255/40011028`、`11293/40011026`；429、权限、认证、网络失败不能据此判离群 |
| 凭据错误 `100016` | 检查当前 QQ 官方平台 AppID/ClientSecret；认证通道冷却 60 秒，保留状态与历史 |
| 下载/发送失败 | 核对同一任务的阶段、数字状态码和版本；不要只凭目录数量差异、单次超时或 Event loop lag 猜原因 |
| QQ 官方 Markdown 发送失败 | 核对 `reply_mode`、`target_type`、HTTP、`code` 和 `err_code`；只有 `40034105` 表示主动推送被拒绝，不能把所有发送异常当权限问题 |

欢迎/帮助按钮回调使用外层事件编号被动回复群聊或私聊，缺少编号或发送失败时不改为主动推送。`40034100` 为频控、`40034127` 为 Markdown 权限、`40034006` 为内容违规、`40034005` 为消息引用编号过期；旧版仅有异常类型、没有数字码的日志无法还原具体原因。正常请求开始诊断改为 DEBUG。遇到旧日志，请先通过 GitHub 更新或重装、重载并确认启动版本，再用同一次失败的新日志判断。

同进程热重载交接原事件、选书结果、账号、TXT、媒体进度和已确认发送状态，避免重复发送。进程重启仅恢复已有落盘 TXT 的上传续传，不保证恢复未完成正文或纯内存媒体任务。数据库配置、账号或登录凭据改变后，旧网页登录/扫码会话失效。

QQ 阅读在下载或主动刷新资料时核对登录状态。官方明确返回未登录后，后台账号卡片和详情显示“登录已失效，请重新登录”，下载提示联系管理员重新登录；网络超时不会标记失效。重新保存账号后恢复待验证，验证成功恢复正常状态。

QQ 阅读搜索支持展开系列书单中的单本书，不把系列编号当作书籍编号。搜索使用 Android App 的 `common/result/search_txt` 文本搜索接口，携带书籍类型 `type=1`，替换间歇返回 HTTP 200 空正文的旧版搜索路径，不使用网页搜索。搜索不等待正文解密密钥池；空响应、格式异常和瞬时网络故障在 10 秒内最多请求三次。指定 QQ 阅读搜索重试后仍遇到异常时提示“QQ阅读搜索失败，请稍后再试”，不缓存为无结果；正常空列表仍提示没有相关书籍，候选目录与免费章节校验保持不变。

指定平台找书（如“番茄找神豪？别，还是叫我绅士软饭王吧”）只查询该平台，等待提示、结果标题、翻页及无结果/失败提示均显示指定平台。番茄搜索使用App接口GET查询参数，网络或业务错误提示搜索失败，不冒充没有相关书籍；正常空列表才显示没有找到。

番茄搜索复用异步会话，每次搜索总预算10秒，单次请求最多4秒，同页最多三次尝试；仅对业务码5000、超时/断流及HTTP 408/500/502/503/504有界重试，429及其他拒绝不自动重试。5000不代表已确认限流或账号失效；首页异常提示搜索失败，后续页异常保留已匹配的候选并跳过缓存。每页先按完整原词筛选再限制数量。长查询完整包含至少8字书名、且书名占查询一半以上时保留为较低档相关结果，完整查询精确命中仍优先，多词作者匹配规则不变。

聚合找书有匹配就显示已取得的书籍。部分平台未完成且没有匹配时，提示已完成的平台未找到相关书籍；所有平台均失败时提示重试。结果不完整时跳过搜索缓存，下次重新查询；完整空结果正常提示没有找到。

盐言/知乎公开查询仍共用至少3秒串行间隔。403按实际被拒绝的官方主机分别冷却10分钟，文章接口拒绝不再阻断另一主机的章节信息；429维持整个官方通道冷却。旧版本共同冷却保留至到期。日志区分真实响应(remote)、错误缓存(error_cache)和本地冷却(channel_cooldown)，仅真实拒绝记WARN；不据403猜测账号失效、文章下架或请求过频，也不跳过详情及正文校验。
