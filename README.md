登录后先选择 QQ 官方机器人，再进入它的独立控制台；侧栏“退出机器人”返回选择页，“退出登录”退出管理员会话。选择页以可整张点击的卡片展示头像、名称、在线状态和各机器人已记录的群聊、用户数量，支持键盘进入与手机布局。统计来自现有消息记录，未知时显示“—”，不作为 QQ 官方累计数量。停用机器人仍可编辑业务配置，但发送和群管需要该机器人实际运行。页面可见时每分钟更新公开资料，单个账号资料读取失败不影响其他账号；未进入控制台或关闭网页仍继续接收消息。

小说开关、测试模式、管理员白名单、主分享网盘、网盘账号和目录、QQ阅读账号、群广告开关及页面布局等按认证 AppID 独立保存，并在对应机器人的聊天及后台下载中使用。AstrBot 插件配置的 `bot_profiles` 保存各机器人的业务配置快照，运行状态仍使用 MySQL `mantou_runtime_state` 并按机器人隔离；首次读取独立作用域时兼容原有设置，后续互不覆盖。数据库连接、网页监听与控制台登录属于同一服务的公共设置。聊天列表、历史、实时消息和群状态同时按 AppID、聊天类型与会话编号隔离；退出或切换后旧请求不回填当前页面，账号弹窗及可见凭据会清空。

下载提示、完成按钮等公共 Markdown 发送入口始终使用本次认证客户端的 AppID 记账和查询群权限，身份缺失或发生变化时停止提交，不再回退列表中的首个机器人。已有错记的历史不会仅凭相邻消息、群名或机器人名称自动改写。

网页群聊输入框输入 `@` 可选择全体成员或当前群已有资料的成员，显示头像，候选数量不截断，支持搜索和方向键/Enter 选择；全体提及需要机器人具有群管理员权限。粘贴或选择的 PNG、JPEG、GIF、WebP 图片（不超过 10MB）使用 QQ 官方素材预上传，再以 Markdown 发送，保留原始图片与动画。

会话列表宽度和编辑区高度可拖拽调整，并按当前机器人保存；刷新时按已保存的尺寸恢复。

引用消息支持按当前聊天的完整 QQ 消息 ID/引用索引精确定位；数据库行号不作为消息定位 ID，引用链中的消息仍可通过其真实消息 ID 或引用索引跳转。多引用字段冲突时保留预览；带官方引用标识的预览可点击重新定位，未匹配时不猜测原消息。

QQ 群资料查询遇到 `100016` 时，表示机器人 AppID 或 ClientSecret 不正确，应在 AstrBot 对应 QQ 官方平台配置中核对。插件按当前认证通道冷却 60 秒，保留群状态、资料和历史，避免按每个群重复请求与告警；其他机器人不受该通道影响。

群状态和群资料 GET 复用 SDK 认证会话，完整读取有界响应并记录真实 HTTP 状态和数字业务码。同一机器人、群与接口的并发查询合并；失败进入冷却，强制刷新也不重复请求。“机器人非群成员”等查询失败保留原成员状态，只有可信退群事件确认移除。

群人数按当前机器人和会话使用已取得的官方资料，列表刷新、缺失字段和旧版零值占位不会清除已知人数。真实人数增减正常更新，尚未取得官方人数时显示“人数未知”。

消息列表只列出存在聊天记录的会话，群资料和失败查询占位不再生成空条目。右键会话可选择“删除会话及记录”，查看预览后确认；空会话也可处理，清空后从列表移除，保留预览后收到的新消息。消息记录页右上角仍可清理当前会话或当前机器人的全部记录。

单个群会话删除且没有后续新消息时，同时退出资料刷新队列，网页强制刷新及在途旧结果也不再恢复查询。后台轮询只覆盖真实聊天记录中的群，保留已从内存淘汰的数据库历史；新群消息或可信加群事件可恢复查询，群备注、资料及 QQ 成员状态继续保留。

聊天消息身份标签：官方消息确认机器人时显示蓝色 `BOT`，群主显示橙色标签、管理员显示绿色标签；普通群聊发送者显示灰色“群成员”，具体角色尚未返回时同样保留该展示标签，权限角色仍保持待确认。自己消息的身份与已知群角色同样固定显示在昵称旁，无需悬停。连续消息保留清晰间距，其他机器人保持接收方消息布局，历史记录和实时消息使用同一身份标识；未知角色不猜测。

消息气泡下方不再显示悬浮的时间、消息编号和操作栏；右键消息或长按打开菜单，集中提供引用、复制、撤回、禁言和原始数据等适用操作。自己发送但没有平台原始回包的消息展示本地发送记录快照，并明确标注其来源；失败或待发送消息不展示快照。键盘聚焦消息后可按 Shift+F10 打开菜单；图片消息同时保留复制图片。禁言倒计时和发送失败重试状态继续显示。

聊天主区右侧滚动条加宽，并在浅深主题中使用更明显的滑块与轨道配色。向上翻离底部时，右下显示“回到底部”；有新消息时保留数量提示，引用定位窗口仍可“返回最新消息”。消息滚动区独立分层，长气泡在悬停或键盘聚焦时也不会盖住浮动按钮；右键菜单和弹窗仍显示在更高层。回到底部后按钮收起，减少动态效果偏好下直接滚动。

找书使用 `找书名` 或 `找作者` 等文字查询；含分享链接的输入不作为搜索词，交由已有平台链接识别流程处理，避免将链接参数误送到搜索接口。QQ 官方发送记录使用实际认证 AppID 与真实会话目标；旧平台名称作用域保留历史记录，不提交错误群资料请求。

## 快速开始

### 公开仓库安装

AstrBot WebUI 插件管理中可添加仓库地址：

```text
https://github.com/TimShitPig/mantou_Bot
```

也可以手动安装到插件目录：

```bash
git clone https://github.com/TimShitPig/mantou_Bot.git /AstrBot/data/plugins/馒头bot
```

安装后到 AstrBot WebUI 的插件管理里重载插件。

重载时先交接正在运行的任务，消息入口和帮助网页恢复后，数据库摘要、登录态、公网地址及缓存维护在后台加载。首次成功建表后，同一数据库配置在当前进程内复用结构初始化结果；数据库失败时保留待写数据，冷却后再试。启动日志分别记录基础服务、后台恢复及停止交接耗时。

同一 AstrBot 进程内热重载会恢复被中断的小说任务，并继续回复原聊天；正文未完成时重新执行下载，已生成 TXT 时复用原文件和网盘账号，已取得的分享继续发送，已确认发送的提示和完成消息不会重复发送。夸克媒体归档逐项接管未完成的媒体上传及元数据写入，上传中的临时文件保留到子任务结束再删除；已提交但结果不明的项目不自动重传。进程重启时，未生成 TXT 的小说下载和仅在内存中的图片任务不恢复；已经落盘的 TXT 上传任务仍按原有续传机制处理。

聊天媒体使用消息所属机器人的“网盘配置 → 夸克”默认账号，不跟随各群的小说网盘或账号选择；默认账号需启用并配置有效 Cookie。更换默认账号只影响新任务，已有归档按上传时绑定的账号读取；删除该账号会影响其历史媒体读取。新生成 TXT 的续传元数据保留机器人 AppID；多机器人环境中缺少身份的旧上传任务保留等待，避免借用其他机器人的账号续传。

### 网页帮助

网页顶部、控制台卡片和运行状态中的插件版本，统一使用当前实际加载的插件注册版本，启动和热重载时自动同步。

控制台其他页面与登录页沿用夜航蓝界面；消息记录页采用 QQ 三栏布局：窄图标轨道、会话列表和聊天主区，左上只保留机器人头像，不显示名称或搜索框。右上角“⋮”集中提供当前会话的网盘账号、广告拦截、刷新群信息、群备注、群设置、刷新和清理记录等原有操作；主题切换、管理员菜单和“退出机器人”放在窄轨道底部，“退出登录”仍在管理员菜单内。会话列表宽度与编辑区高度可拖动调整，也可独立折叠；手机进入聊天后显示返回列表入口，发送按钮保持可见。浅色主题使用白灰底色与淡蓝发送气泡，深色主题使用炭灰底色与藏蓝发送气泡，引用、链接和附件卡片同步配色。消息页按确认的参考图校准文字字重、灰色昵称、标题位置、会话间距及浅深主题的柔和渐变和边框，文件图标与附件卡片同步调整；左侧导航及原有消息业务保持。

“全部”默认平铺群聊和私聊会话；列表的分组按钮在悬停或键盘聚焦时显示，仍可切换按类型分组并折叠群聊、私聊分组。桌面消息页的文字、头像、气泡和间距缩小约 25%，会话行高同步为 66 像素；新布局默认会话列表宽 273 像素、编辑区高 173 像素，已有保存的尺寸继续按原值恢复。手机端保留可读文字和合适的触控尺寸，其他页面布局保持。

首次访问默认深色，主题选择保留本设备偏好，通过约 320 毫秒整页快照渐变切换，快速连点合并到最后选择，控件反馈遵循减少动态效果设置。消息原始数据、群备注、禁言和清理记录窗口支持 Esc 关闭、Tab 圈定和关闭后焦点恢复；引用定位、媒体播放与未变化消息节点继续保留，手机返回列表后可重新打开当前聊天。

无需填写域名。插件默认监听 `0.0.0.0:8090`，启动时自动获取服务器 IPv4；重载插件后管理员发送 `帮助`，管理菜单会直接显示“打开网页版帮助”按钮，地址格式为 `http://服务器IP:8090`。同配置热重载保留当前登录；账号、密码或数据库配置改变后需重新登录，旧版未绑定凭据的持久会话不再恢复。打开后先进入独立登录页，使用帮助网页设置中的账号密码登录管理员控制台；登录前不会返回侧边栏、功能页或控制台结构，登录后可查看小说开关、网盘摘要、数据库状态和服务器运行状态。

控制台的“机器人配置”提供管理员白名单和帮助网页设置；管理员白名单会与 MySQL `mantou_runtime_state` 双向同步，AstrBot 配置和数据库任一侧变更后会在下次同步时保持一致。“网盘配置”保留 UC、夸克、百度顶部页签，每个平台下方以 OpenList 风格的紧凑可点击卡片展示账号和设置项；账号卡可进入详情并独立启停或删除，也可分别设置 UC、夸克、百度各自的默认账号和上传目录；Cookie 通过添加账号入口配置。系统设置可查看连接状态并编辑数据库地址、端口、用户名和数据库名，数据库密码只写入、不回显，留空表示保持现有密码；数据库名留空时默认使用用户名。数据库连接配置保存后需重载插件生效。系统设置的“测试当前连接”直接使用尚未保存的表单，空密码沿用已保存密码，仅执行 SELECT，不保存配置或创建数据库、表；测试结果独立于已保存连接状态，显示固定错误分类、MySQL 数字码、服务端版本与 TLS 状态。全局默认分享网盘与每个平台的默认账号分别保存。消息记录页右上角“⋮”菜单可为当前群单独选择网盘账号，未单独设置的群使用全局默认分享网盘及该平台默认账号；每次下载只向所选网盘上传并生成分享链接；QQ阅读提供独立多账号卡片，可添加、删除、切换当前账号和启停账号，查看会员类型与到期时间，并通过手机号验证码或手机 QQ 扫码登录。账号列表仅展示卡片，点击后弹出居中详情；添加账号也使用弹窗，背景遮罩并轻度模糊，关闭后保留列表位置。Cookie、密码和数据库密码等敏感凭据不回显；QQ阅读详情中的密钥仅在登录控制台后点击“显示”时按需读取，隐藏、离开详情或退出登录即清除页面中的密钥。

消息历史按页查询，同参数的并发请求复用一次查询，完成后释放；消息展示使用副本，保留完整原始记录并合并最新撤回状态。

群聊“已移除”只由当前机器人收到 QQ 官方 `GROUP_DEL_ROBOT` 事件确认；资料接口的 HTTP 404、未开放白名单权限（11253）、认证、限流或网络失败保留原有成员状态，群号和成员 OpenID 中包含 `404` 也不会判为移除。旧版没有明确退群事件依据的“已移除”恢复为待确认，保留聊天记录与群资料；`GROUP_ADD_ROBOT`、新收到的群消息或成功读取的群内状态可恢复在群。状态来源与修订号随缓存、热重载和网页更新保留，迟到结果不覆盖较新状态。依据：[官方群退出事件](https://bot.q.qq.com/wiki/develop/api-v2/autogen/event/group_del_robot.html)、[官方状态接口](https://bot.q.qq.com/wiki/develop/api-v2/autogen/api/v2_groups_group_openid_bot_state.get.html)及[官方错误说明](https://bot.q.qq.com/wiki/develop/api-v2/openapi/error/error.html)。

入群和退群记录优先使用事件真实昵称、当前群资料及已保存的身份关联资料，历史分页批量补齐已知姓名；后续收到真实昵称时更新原通知，不新增消息或未读。欢迎消息中的 `@成员` 由 QQ 客户端显示姓名，接口未返回的名字不凭空推断；从未收到姓名且成员资料接口无权限的用户保留占位。当前页面的实时资料按群、聊天类型和 AppID 隔离。

QQ 官方 `FRIEND_ADD`、`FRIEND_DEL` 事件会按机器人和用户记录好友关系，并在对应私聊显示添加或删除好友的系统通知；删除好友保留原聊天记录。重复事件不重复计数，迟到事件不覆盖较新的关系状态。

普通用户发送 `帮助`，或在群内单独 @机器人（管理员也适用），会显示“小说列表、如何下载、添加机器人”公开按钮；附带正文、附件或引用的 @消息继续原处理。管理员发送 `帮助` 仍进入管理菜单。公开菜单按真实消息 ID 短期去重；好友链接通过当前认证生成，私聊不传来源群，生成失败时保留前两个按钮。

入群欢迎保留“使用教程”和“小说列表”两个入口，每排最多两个；“如何下载”已合并到使用教程，旧消息中的下载方式回调继续打开同一教程。小说列表只用纯文字列出已开启平台，每行两个，不附下载介绍；教程和列表回复均不附底部按钮。欢迎消息仍通过 QQ 官方生成分享链接接口增加“添加机器人”按钮；链接生成失败时继续发送原欢迎内容。

机器人被拉进群的欢迎使用 `GROUP_ADD_ROBOT` 真实事件编号 `event_id` 发送被动回复，兼容官方 SDK 与旧版事件桥；缺少编号或被动发送失败时停止，不转换为主动推送。普通新成员加入的 `GROUP_MEMBER_ADD` 欢迎沿用主动消息权限检查。

“使用教程”按分享链接、`找xx`（书名或作者，必须带“找”）、点击书名/作者并发送选书指令、点击“打开”四步说明，在同一条 Markdown 消息中逐步配上四张示例图。AstrBot 插件配置或网页“帮助网页”中的“使用教程图片宽度（像素）”对应 `help_web_settings.welcome_tutorial_image_width`，默认 480，范围 160～1080，高度按原图比例自动计算。四张原图随插件发布，只有 `/tutorial-images/` 的固定四个文件名公开读取；帮助网页外网地址须能从公网访问，反向代理需同时转发该路径。聊天附件及控制台 API 仍受原鉴权保护。

实时新消息与历史页都提供“原始数据”入口，网页预览最多 3000 字符并标注截断，不改变数据库完整原文。私聊右上角“⋮”菜单中的“刷新”会重新查询已存联系人与全部关联群资料并重试头像；事件明确提供非空但不可见的空白昵称时，名称区域留空并保留头像和身份标签；真正缺少昵称字段仍显示占位，空白值不覆盖已知可见昵称，原始事件不变。已有原图的图片表情包只显示原图及用户真实文字，不重复显示平台描述。QQ 图片 Markdown 按原媒体顺序显示图片和文字，不显示尺寸标记链接；`<@all>` 显示为 `@全体成员`。

如果使用域名或反向代理，可以在 AstrBot 插件配置的“帮助网页设置”中填写外网地址覆盖自动地址，例如：

```text
帮助网页外网地址: https://help.example.com/
帮助网页监听地址: 0.0.0.0
帮助网页监听端口: 8090
帮助网页登录账号: admin
帮助网页登录密码: 请填写长随机密码
```

将域名或反向代理转发到监听端口后重载插件。QQ 官方帮助菜单会显示“打开网页版帮助”按钮。消息收发、群管和文件发送只处理 QQ 官方适配器（`qq_official`）。网页使用响应式布局，手机和电脑均可访问。消息记录页从窄图标轨道底部切换浅深主题，控制台其他页面与登录页保留右上角主题入口；选择会保存在当前浏览器。支持 View Transition 的浏览器使用约 320 毫秒整页渐变，消息图片与滚动位置保持不变；首次加载、减少动态效果及旧浏览器沿用直接更新。消息页深色主题使用分层炭灰底色、蓝色操作控件与藏蓝发送气泡，输入框、弹窗和状态文字同步配色；其他页面保留原有夜航蓝设计。服务器位于 NAT 或容器网络时，需要把监听端口映射到外网。

### 私有仓库安装

GitHub 没有“公开但不可被搜索”的模式。若仓库为 Private，AstrBot 无法匿名拉取，需要在服务器上使用带权限的方式同步：

```bash
git clone https://<用户名>:<token>@github.com/TimShitPig/mantou_Bot.git /AstrBot/data/plugins/馒头bot
```

之后更新插件：

```bash
git -C /AstrBot/data/plugins/馒头bot pull
```

更安全的方式是在仓库 `Settings -> Deploy keys` 添加服务器 SSH 公钥，然后使用 `git@github.com:TimShitPig/mantou_Bot.git` 拉取。

<summary>群管功能</summary>

QQ 官方群消息包含连续 9 到 12 位数字时，插件会尝试撤回。群名片、JSON 卡片、空间相册分享、合并转发和 QQ 闪传也会进入同一撤回模块。

起点读书的官方 `qidian.com` 及其子域名分享链接属于小说白名单，图文 H5/JSON 书籍卡片不会仅因卡片类型或链接中的书籍编号触发撤回、禁言；夸克/百度网盘分享广告仍优先拦截。

QQ 群主和管理员不会被自动撤回；插件使用 QQ 官方事件中的成员角色，并在可用时查询官方群成员角色。

普通成员命中规则后，从已接收的本地消息记录联动撤回同群该用户最近最多 30 条（包含触发消息），不按消息年龄过滤。广告类消息撤回并成功禁言后，只会发送一条“@发送者 / 请勿发送此类消息 / 如果是小说请联系群主”提醒。

数字撤回禁言次数按同一用户跨群累计：群1触发后，再到群2触发会继续递增禁言时长，不会重新从 0 开始计算；处罚只作用于当前触发的 QQ 官方群。管理员可在每个 QQ 官方群发送 `开广告`、`关广告` 或 `广告状态`，独立控制本群自动撤回；默认关闭，状态保存到 MySQL `mantou_runtime_state`。

插件管理员可在 QQ 官方群发送 `踢 @成员`、`@成员 踢` 或 `踢了 @成员`；可同时 @多个成员，去重后单次最多 20 人，默认只移出群聊、不拉黑。直接使用当前事件对应机器人的官方批量移除接口，不以成员列表或详情读取失败提前判断权限；仅官方明确确认移除成功才回复成功，同一条消息不会重复提交。网页群设置继续提供官方批量移除和黑名单管理；基础设置显示官方群简介、群分类和群标签，还原字符实体并保留简介换行，复用已保存群资料，点击群资料刷新后同步更新。群设置同时提供禁言状态查询，显示全员模式、定时和周期规则及当前被禁言成员；使用当前群和机器人认证，复用状态缓存及后台刷新。单成员禁言默认 7 天，`禁 @成员 1` 表示 1 天，带 `秒`、`分`、`时`、`天` 时按对应单位计算；消息收发和群管只使用 QQ 官方接口。

<details>
<summary>小说下载与文件出口</summary>

所有模块统一写入文件缓存分类。AstrBot 环境下写入数据目录的 `mantou_bot_file_cache/`，非标准本地目录使用 `功能文件/文件缓存/`；目录按 `小说缓存/`、`媒体缓存/`、`临时缓存/`、`消息记录缓存/` 和 `其他缓存/` 分类。插件启动时会把旧小说缓存、媒体副本、临时上传文件及旧消息缓存迁移到新目录；上传中的小说文件和续传任务保留原路径直到可安全迁移。小说 TXT 只用于当前群选定的网盘生成分享链接，不直接通过 QQ 发送；插件启动或重载时会清理上次运行遗留的非占用缓存，UC、夸克、百度配置目录作为总目录，新上传小说按服务器本地日期进入 `总目录/YYYY年M月D日/原文件名.txt`，例如 `/小说机器人/2026年10月13日/小说.txt`，同一天复用同一子目录，续传按实际上传日期归档。运行期间每天本地零点清理本地小说缓存、网盘总目录旧 TXT 及日期子目录中前两天及更早的 TXT，今天、昨天以及仍在上传或等待续传的文件会保留。过期日期目录清理后再次确认已空才删除，总目录、非日期目录、有其他文件或子目录的目录保留；无法确认远端时间的文件继续跳过。

QQ 原附件地址明确返回签名过期码 `-5503007` 时，归档队列保留记录并停止对该地址重复请求；其他临时失败继续有限重试。同一 QQ 附件获得新的 rkey 地址后按原索引更新，尚未提交的项目恢复归档，不移动已保存的网盘绑定。尚未归档且地址已经过期的历史媒体，需要新的官方可读地址或重新发送原文件后补存。

新聊天媒体归档到夸克默认账号的 `/QQ聊天媒体/YYYY年M月D日/`，按消息时间的服务器本地日期创建和复用目录，无有效时间回退当天。此目录及其子目录不参与小说 TXT 定时清理。等待元数据不设 128 条拒收门槛，最多同时执行两项任务；同进程热重载保留等待项、上传子任务及逐项进度，进程重启不恢复仅在内存中的等待项目。

QQ 图片、动画、视频、音频、普通文件和机器人发送后记录到的官方媒体 URL 按 `media.items` 原始索引独立归档。直接上传原文件，不转码、不压缩、不生成 ZIP；插件单项处理上限为 5 GiB，沿用分块下载、流式哈希和文件流上传；夸克账号容量及上传准入以服务端实际响应为准。超限项目停止重复重试，上限提高后仅恢复此前因旧上限失败且尚未提交的项目。上传期间仅在 `临时缓存/` 写入并保持活动占用，流程结束删除；远端已确认的文件 ID 复用于元数据写入，不重复上传，已提交但结果不明的项目保留防重复状态。MySQL `media._quark_archives` 按索引保存原账号身份、文件 ID、类型、大小和名称。已有蓝奏云分享和 ZIP 归档保留只读兼容，新版不再提供蓝奏云上传与 Cookie 配置，也不批量搬迁或删除历史文件。

网页历史与实时消息仅返回登录保护的同源代理。读取时用原账号向夸克获取临时下载地址，成功完整传输后内部缓存最多 300 秒，过期或打开失败重新解析一次；不会向网页或日志公开直链、Cookie、分享信息。逐跳校验公网 HTTPS 和夸克域名后发送下载认证，支持音视频 HTTP Range 和普通文件原名称下载，不保存读取副本。旧蓝奏云只读流程保留完整有界分享页/ESA 解析、ZIP_STORED 偏移与 CRC 校验。没有服务器可读源地址的浏览器私有媒体继续使用原浏览器缓存；收到 QQ 官方附件 URL 后再归档。旧媒体副本清理与语音/网页上传临时文件沿用现有文件缓存规则。

聊天记录在同一会话收到新消息时，会保留未变化消息及其图片、音视频节点，避免整页重复渲染打断正在读取的媒体。媒体代理区分上游请求、读取和下游响应准备、写入、结束；浏览器切换聊天、关闭预览或连接中断导致的下游连接异常按调试日志记录，真实的上游连接、分享解析、下载和内容校验失败继续按阶段告警，并记录上游状态及成功写入字节。QQ 媒体代理的连接获取预算为 30 秒（包含连接池等待），实际新连接建立限制为 10 秒；图片总超时仍为 30 秒，文件不设总超时，每段读取超时仍为 60 秒。

图片和表情包不以 JPG/PNG 后缀作为保存白名单：JPEG/JPG/JFIF、PNG/APNG、GIF 动图、WebP、BMP、TIFF、ICO、HEIC/HEIF、AVIF、JXL 等只要 QQ 提供可下载附件，就按原始字节归档；其他未知后缀也保留。无后缀图片按附件 MIME 和文件头识别，GIF 不抽帧、不转 JPG。官方 msg_elements 中递归附件同样提取，多图逐项处理；事件对象和 raw_data 的镜像附件合并去重，真实重复图片保留出现次数。只有 QQ 内置表情编号/标签、没有附件 URL 时，保存表情文字/编号和原始消息，不伪称已取得图片文件。机器人发送挂钩从官方媒体组件的远端 URL 提取附件，兼容 ComponentType 枚举并保存 Face 编号；本地路径、Base64 和浏览器私有缓存不作为远端附件，等待官方回显 URL 后归档。原始格式的保存不等同于浏览器支持直接预览所有格式。

网页或机器人发送图片、视频和文件时使用 QQ 官方富媒体接口；聊天媒体不经过图床或 COS。

所选网盘上传成功后，QQ 官方机器人会发送该网盘的链接按钮；上传失败时只回复 `文件发送失败，请稍后再试`。

夸克同账号的目录解析、同名清理、上传完成与每日旧文件清理共用操作锁，避免不同小说同时写入使偏移分页错位；不同账号仍可并行，分享阶段继续由同名锁保护。Cookie 正常刷新不触发重扫；扫描发现不一致后丢弃旧页，从首页重新读取，返回前复验首页与总数，完整性检查失败时停止后续操作。

夸克目录、任务及分享列表 GET 遇到 `15020 / query fail [61004]` 时最多请求三次；上传、删除和创建分享 POST 不自动重放。分享任务必须确认完成，失败或超时即停止；已有分享 ID 时优先按该 ID 取链接，列表回退严格匹配同一分享 ID。后端错误日志记录阶段、HTTP/业务码和页码，不拼接响应原文。

消息记录页的“清理记录”支持当前会话或当前机器人全部记录，先预览再确认；只清理预览边界内的记录，保留之后收到的新消息。按 AppID 隔离，保留群资料、备注、设置和网盘文件，不撤回 QQ 消息；清理过程继续接收消息，事务完成后同步内存与在线页面，未配置数据库时仅清理内存。

配置可用 MySQL 后，聊天历史不按条数或时间自动删除，群聊和每个私聊分别按会话分页读取；内存只保留热点副本，内存淘汰不影响数据库中的历史或媒体归档元数据。网页单次最多读取 100 条，并可继续加载更早记录，不代表只保存 100 条；未配置数据库时仍只保留当前进程的有界内存缓存。旧版本已删除的记录不会凭空恢复。

点击消息气泡中的引用框可跳转并高亮原消息，也支持键盘 Enter 和空格。原消息不在当前页时，按当前聊天类型、会话和机器人 AppID 精确查询附近记录，可继续加载前后消息或返回最新消息；定位期间不会被后台刷新或新消息拉回底部。引用标识未匹配到原记录时，优先显示 QQ 随消息提供的首层引用文字或媒体类型摘要；这类预览不猜测作者，也不提供原消息跳转。只有既无精确原记录又无随附引用内容时才显示不可用提示。历史长消息同样补全有界引用预览，不修改原始记录。QQ 附件的 `attachmentType/attachmentIndex` 位置标签只在匹配已保存媒体序号及类型时消费，并按原位置显示附件；标签外文字保留，原始数据和归档不变。

昵称补全与私聊主动刷新的元数据读取在线程池执行，避免同步数据库或备注锁阻塞网页事件循环；元数据五秒缓存从读取完成后计时，失败也短暂冷却。私聊新消息补名及主动刷新先按同 AppID、同用户 OpenID 直接匹配已保存的群聊和私聊历史；列表、搜索及标题在用户资料缺失时也批量读取这条历史路径，命中结果回填自动缓存，主动刷新可更新旧自动昵称，手动备注始终优先。历史按主键从近到远每页读取 200 条，找到有效本人姓名后停止该用户，不限制来源群数量；昵称保存列优先，原始作者或成员资料须与用户身份匹配，不取操作者或引用消息姓名。数据库未命中或失败继续复用同 AppID 的已确认群成员缓存；昵称回查按用户、成员映射和统一身份索引查询，指定群时仅在该群回查原始消息，避免跨全部历史扫描。历史普通消息的有效昵称及明确双 OpenID 关联按主键从近到远分批补入资料索引，进度可恢复，不覆盖更新或同时间的有效资料。各昵称候选先独立校验，占位名和纯不可见字符不挡住后面的真实名字。常规列表复用已保存的用户资料和有效昵称，不重复扫描已命名联系人；直接历史匹配未命中时再跨全部已知关联群及统一身份资料补查；不限制在一个群或前三个群。每个用户独立取最新关联资料，不让其他用户的资料占满整批结果。群聊或私聊历史必须有有效本人昵称，并能通过同 AppID/OpenID 直接匹配、已收到的 OpenID 映射或统一身份关联到私聊用户，才会复用；缺少这些数据时保留占位名，不按相似名字或头像猜测身份。

QQ 附件只返回文件名和大小、下载地址为空时，消息记录仍显示附件卡片与大小，并提示“未提供下载地址”；不会将附件显示为空消息或发起无地址归档。历史记录可从已存原始消息补全，后续有效地址更新同一附件，保留原有多附件归档索引。

消息记录页读取的 QQ 官方群资料保存在 MySQL `mantou_group_infos` 表，重启后直接恢复；官方成员加入/退出事件会即时增减人数并推送到当前页面，后台每分钟检查已知群并以官方资料校准，单群资料至少每小时更新一次且按官方 30 QPM 限制串行请求；网页中的“刷新群信息”会立即请求最新公开资料。
刷新结果同步更新会话列表与聊天标题；空历史、空群名和较旧资料不会抹除已有有效群名，手动备注始终优先。群聊与私聊页签也对实时消息保持类型筛选。

未配置数据库时不会尝试连接 MySQL，小说功能默认全部开启，主网盘默认 UC，相关运行状态无法持久化。

管理员可直接粘贴 UC、夸克、百度或 QQ阅读 Cookie，无需命令前缀；数据库登录态优先于插件配置。保存多个同平台网盘账号后，在目标群发送 `UC换N`、`夸换N`/`夸克换N` 或 `百换N`/`百度换N`，只改变该群对应平台的账号；例如一群发送 `夸换1`、二群发送 `夸换2`，其他网盘选择保持不变。夸克账号可通过 `夸克登录` 扫码或粘贴 Cookie 添加；管理员私聊发送 `夸克账号` 会刷新并显示账号数量和名称。使用 `删夸克N` 或 `删除夸克N` 删除指定账号，至少保留一个账号，插件配置中的账号1需先修改配置后才能删除。

夸克上传前按文件名排序扫描目录，校验服务端页码、实际页宽、条数和总数；目录不一致时最多三轮退避，以每页 100 条串行从头重扫，不拼接旧页。仍缺项时停止删除和上传，保留旧文件；正常扫描保留最多四路分页并发。

夸克账号资料在打开网盘页、切换到夸克或页面恢复可见时自动检查；停留在夸克页期间按五分钟间隔更新昵称、头像、空间和权益。后台共用五分钟查询缓存，失败时保留旧资料，后续周期继续尝试；自动刷新不会覆盖正在编辑的账号配置。未配置数据库时资料只缓存在当前进程，不新增本地文件。

</details>

## 配置

| 配置项 | 说明 |
| --- | --- |
| `group_file_cleanup_admin_qq` | 管理员 QQ 白名单（与 MySQL 双向同步） |
| `help_web_settings` | 控制台监听地址、端口、可选域名和账号密码 |
| `uc_pan_settings` | UC 网盘 Cookie 和上传目录 |
| `quark_pan_settings` | 夸克网盘 Cookie 和上传目录 |
| `baidu_pan_settings` | 百度网盘 Cookie 和上传目录 |
| `zlibrary_account_settings` | 215邮箱 API Key（`zlibrary_mail_api_key`，默认空）和注册表单 rx（`zlibrary_registration_rx`，默认 `215`） |
| `database_settings` | 公共 MySQL 连接；地址支持 IP/域名、host:port、[IPv6]:port 或不含凭据的 mysql://host:port，显式端口须一致；密码只写入、不回显；规范分类字段优先于旧字段，明确留空不回退旧值 |
| `database_ssl_mode` | 数据库 TLS 模式：preferred（默认，服务端提供 TLS 时加密）、required（必须加密）、verify_identity（校验证书及主机名）、disabled（禁用 TLS）；TLS/认证失败不自动降级重试 |
| `database_ssl_ca` | 可选服务器 CA 文件路径，供证书身份校验使用；留空使用系统信任库 |
| `database_connect_timeout` | 数据库连接超时秒数，默认 10，范围 1～60 |

`group_file_cleanup_admin_qq` 白名单内的 QQ 可使用帮助、状态、小说网盘切换、保存网盘与 QQ阅读 Cookie、ZLibrary账号创建、小说开关和群管指令。

### 自动创建 ZLibrary 账号

先在 AstrBot 插件配置填写 `zlibrary_account_settings.zlibrary_mail_api_key`，并配置可用 MySQL；Key 默认空，禁止把真实 Key 写入源码。重载插件后，白名单管理员发送 `注册ZLibrary` 或 `创建ZLibrary账号`，即可启动单次流程。邮箱域名由服务端随机选择，无需指定域名；密码和昵称自动生成。未配置 Key 或 MySQL 时不会创建邮箱；发送成功后等待实际邮件验证码，超时结束，不把发码接口 HTTP 200 当作注册成功。聊天只显示进度和固定结果提示，不显示邮箱、密码、Key、Token 或验证码。账号注册、搜索和下载实现均位于 `功能文件/管理功能/小说功能/小说/Z-Library小说.py`。

小说下载功能全部免费可用，不保留用户激活、卡密、收费、付费或每日免费额度。
