<details>
<summary>查看群管功能</summary>

用户发送的消息中包含连续 9 到 12 位数字时，插件会尝试撤回该消息。群名片、JSON 卡片、合并转发和 QQ 闪传也会走同一个撤回模块。当前消息撤回成功后，会通过 `get_group_msg_history` 拉取最近 100 条群历史，筛选该用户最近消息并逐条调用 `delete_msg` 撤回，默认最多撤回 8 条。

同一成员在同一个群里被本模块成功撤回 3 次后，会调用当前 OneBot 适配器的 `set_group_kick` 踢出该成员；踢出当前群成功后，会通过 `get_group_list` 获取机器人所在群，再用 `get_group_member_info` 检查该用户是否在其它群，存在则一并踢出。

群文件清理管理员白名单内的 QQ 可发送 `@用户 踢` 或 `@用户 踢了` 直接踢出成员，也可以一次 @ 多个用户批量踢出；当前群踢出成功后，会通过 `get_group_list` 获取机器人所在群，再用 `get_group_member_info` 检查该用户是否在其它群，存在则一并踢出。发送 `@用户 踢` 或 `@用户 踢了` 时，还会拉取该用户最近消息并最多撤回 50 条；多个 @ 用户会逐个处理，50 条按每个目标用户单独计算。发送 `开启禁言` / `关闭禁言` 会调用 OneBot `set_group_whole_ban` 开关当前群全员禁言，发送 `开启全部禁言` / `关闭全部禁言` 会先调用 `get_group_list` 获取机器人所在群，再逐群开关全员禁言。

会触发：`123456789`、`你好1078887813`、`你好A1078887813 你好`

不会触发：`12345678`、`1234567890123`、`107888A7813`、`123 456 789`、包含 `http://` 或 `https://` 的链接消息

</details>

## 插件配置

| 配置项 | 说明 |
| --- | --- |
| `group_file_cleanup_admin_qq` | 群文件清理管理员 QQ 白名单，可使用帮助、群文件清理、全部群文件清理、授权链接、番茄小说API切换、番茄/七猫小说开关、付费开关、用户激活、用户重置、激活增减、查询激活用户、生成卡密、查询卡密、复制卡密、查询其他用户激活时间、@用户踢人、开启/关闭禁言和开启/关闭全部禁言，支持一次 @ 多个用户或填写 QQ 号批量操作 |
| `番茄小说key` | 调用 `https://oiapi.net/api/FqRead` 的 OIAPI key |
| `user_activation_daily_free_quota` | 未激活用户每天可免费使用受激活门禁保护功能的次数，按用户 QQ 计数，不按群区分；`0` 表示不开放免费额度 |
| `card_key_sync_used_cards` / `card_key_sync_unused_cards` | 卡密同步列表，和 MySQL 双向同步已使用和未使用卡密；配置删除会删除数据库记录，数据库新增或删除会刷新配置列表，配置新增会写入数据库 |
| `uc_pan_settings` | UC 网盘配置分类，包含 `uc_pan_cookie` 和 `uc_pan_upload_dir`；填写 Cookie 后小说 txt 会先上传到 UC 网盘 |
| `database_settings` | 数据库配置分类，包含 `user_activation_database_host`、`user_activation_database_port`、`user_activation_database_user`、`user_activation_database_password`；数据库名默认与用户名相同 |

群文件清理管理员白名单内的 QQ 可发送 `@用户 激活` 或 `激活 @用户` 激活成员，未填写天数时默认 30 天；也可发送 `@用户 激活 90` 或 `激活 用户QQ 90` 激活 90 天。已激活用户再次使用普通激活时不会重复写入，会提示用户已激活。发送 `@用户 重置`、`重置 @用户` 或 `重置 用户QQ` 会取消该用户激活；管理员可以一次 @ 多个用户或填写多个 QQ 号批量激活、重置或查询。`@用户 增加 5` / `增加 用户QQ 5` 会在原有到期时间基础上增加 5 天，`@用户 减少 3` / `减少 用户QQ 3` 会减少 3 天，调整后已到期则取消激活。管理员发送 `生成卡密` 默认生成 1 个 12 位卡密，也可发送 `生成卡密 数量` 批量生成，单次最多 200 个；卡密默认激活 30 天，用户直接发送卡密给机器人后激活本人，卡密前后带普通文字也可识别，但只从可见文本或 text/plain 消息段识别，并且只有数据库中真实存在的卡密才会回复；不存在的卡密候选会被忽略，不会回复卡密无效，中间断开、插入字符或卡片/群名片隐藏字段不会拼接识别，同一卡密只能使用一次。管理员发送 `查询卡密` 会先显示 `1. 已使用`、`2. 未使用`、`0. 返回上一步`，选择 `1` 或 `2` 后分页查看对应卡密；也可直接发送 `查询卡密 使用` 查看已使用卡密、`查询卡密 没使用` 查看未使用卡密，或用 `查询卡密 QQ号`、`查询卡密 @用户`、`查询卡密 卡密` 筛选，发送 `下一页` / `下` / `上一页` / `上` 翻页；卡密列表会在使用状态后同一行显示 `----xx天`。已有卡密查询结果时，管理员可发送 `复制` 按当前查询条件输出全部卡密，格式和生成卡密一样一行一个；发送 `复制 30`、`复制30` 或 `复制 30天` 只输出对应天数的卡密。插件配置里的卡密同步列表和 MySQL 双向同步：删除配置列表里的卡密会删除数据库对应记录，删除数据库里的卡密会在插件同步配置时删除配置列表里的对应项，数据库新增卡密会刷新新增到配置列表，在配置列表按格式新增卡密会写入数据库。管理员发送 `查询用户` 可查看当前群已激活用户，每页 10 条，发送 `下一页` / `下` / `上一页` / `上` 翻页，列表按剩余时间从少到多排序，并显示 QQ 号、卡密号和剩余时间。如果需要唤醒机器人后手写目标，可使用 `@机器人 激活 用户QQ`、`@机器人 重置 用户QQ` 或 `@机器人 查询 用户QQ`。普通用户发送 `查询` 可查询自己的 QQ 号、卡密号、激活天数、剩余时间、激活时间和结束时间；管理员可发送 `@用户 查询`、`查询 @用户`、`查询 用户QQ` 或 `@机器人 查询 用户QQ` 查询其他用户。激活、重置和查询命令都优先处理消息里被 @ 的用户，不会把 `@用户 激活` / `@用户 重置` / `@用户 查询` 识别成操作发送者本人；同时 @ 机器人和多个成员时会跳过机器人，只处理成员。激活记录按群和用户保存。群文件清理管理员白名单内的 QQ 可发送 `开启付费` / `关闭付费` 控制本群激活门禁，默认各群开启；`关闭付费` 只影响当前群，本群未激活用户可直接使用受门禁保护的功能，小说下载不消耗每日免费额度，也不显示剩余免费本数。未激活用户使用随机英文单词、随机一言、疯狂星期四、古诗词名句、七猫小说下载或番茄小说下载时，若 `user_activation_daily_free_quota` 设置为正整数，则同一用户 QQ 每天可免费使用对应次数，不按群区分，换群不会重置次数；小说下载开始提示会在 `正在下载中请稍等.....` 下方显示剩余免费本数，最后一本会提示可购买 VIP 无限下载，次数用完后回复当日免费次数已下载完并分行提示看群公告或第二天继续免费下载。设置为 `0` 时不开放免费额度。管理员不受激活门禁和免费额度限制。用户激活、卡密、每日免费额度、按群保存的付费开关状态、番茄 API 当前选择和小说功能开关状态只使用 MySQL 存储，不再使用本地 JSON；数据库配置在插件配置最下面的 `database_settings` 分类内，数据库名默认与用户名相同，插件会自动创建内置表 `mantou_user_activation`、`mantou_user_activation_cards`、`mantou_user_free_quota` 和 `mantou_runtime_state`。

群文件清理管理员白名单内的 QQ 可发送 `帮助` 查看 `主动触发` / `被动触发` 大类，随后在 120 秒内发送数字进入小类，再发送数字查看触发指令列表，再发送数字查看详情；发送 `0` 返回上一层。也可直接发送 `帮助 1` 查看指定大类。普通成员无法触发帮助功能。

群文件清理管理员白名单内的 QQ 可发送 `开启番茄` / `关闭番茄` 和 `开启七猫` / `关闭七猫` 开关对应小说下载功能，状态写入 MySQL 的 `mantou_runtime_state` 表，重载后继续生效。关闭后用户发送对应小说链接会直接回复该功能已关闭，不进入下载流程。

插件配置里填写 `uc_pan_cookie` 后，番茄和七猫小说下载完成会先把完整原小说 txt 上传到 UC 网盘，上传目录读取 `uc_pan_upload_dir`，默认 `/小说机器人`，远端同名旧文件会在上传前删除。UC 上传成功后，QQ 收到的仍是和原小说同名的 txt 文件，但文件内容只有 `请复制链接打开UC网盘` 和 `链接：xxx`；UC 上传失败时会回退发送完整原小说 txt。`uc_pan_cookie` 留空时保持原来的 QQ 文件发送方式。

群文件清理只调用当前 AstrBot 适配器暴露的 OneBot 扩展接口 `get_group_root_files`、`get_group_files_by_folder` 和 `delete_group_file`，不会连接 NapCat 或 NapCat WebUI。删除阶段使用有限并发逐个调用 `delete_group_file`，默认同时删除 200 个文件；发送 `清理全部群文件` 会先调用 `get_group_list` 获取机器人所在群，再逐群执行同一套群文件清理逻辑；`qq_official` 事件只返回 `group_openid`，不能直接当作数字 QQ 群号；当前适配器没有 `api.call_action` 或返回非数字群号时，插件会输出 `群文件清理事件诊断` 日志用于查看真实事件参数。

七猫小说下载完成后会临时写入 `功能文件/下载缓存/`，UC 网盘未启用或上传失败时优先通过 AstrBot `File` 组件上传到 QQ，无法使用时再回退 OneBot 本地路径上传。通过 `File` 组件发送时会延迟清理缓存，避免适配器读取前文件被删除；OneBot 回退上传尝试结束后立即删除 txt 文件。发送文件名格式为 `[完结]书名：xxx 作者：xxx.txt` 或 `[连载]书名：xxx 作者：xxx.txt`。txt 文件顶部会写入免责声明，文件发送成功后不再额外发送完成提示，只有发送失败时回复错误原因。

番茄小说识别 `fanqienovel.com`、`changdunovel.com`、`fqnovel.com` 和 `novelfm.com` 链接，支持 `changdunovel.com/t/短码` 分享短链和 JSON 卡片中的链接。下载前会先回复书名、作者、状态、章节、字数和 `正在下载中请稍等.....`，外部提示不显示简介，txt 文件头部会保留简介。群文件清理管理员白名单内的 QQ 发送 `查看API` 会列出番茄小说下载 API，随后发送 `1` 切换到 OIAPI，发送 `2` 切换到析API；当前选择会写入 MySQL 的 `mantou_runtime_state` 表，重载后继续生效。两个接口不会自动互相切换，当前接口失败时会直接返回当前接口的错误。选择析API时，书籍详情仍优先使用番茄官方落地页和官网页面接口，目录和正文使用析API。析API正文会保留段落换行，txt 统一使用 CRLF 换行。文件写入 `功能文件/下载缓存/`，UC 网盘未启用或上传失败时优先使用 AstrBot `File` 组件发送；无法使用时再尝试裸本地路径和 `file://` URI 的 OneBot 上传接口。通过 `File` 组件发送时会延迟清理缓存，OneBot 回退上传尝试结束后删除缓存 txt，成功时不额外发送完成提示。

QQ 官方机器人 `qq_official` 发送文件应优先走 AstrBot `File` 组件，它会封装官方富媒体接口并发送 `media` 消息；如果 QQ 官方群聊返回 `call inner proxy error`，这是平台富媒体上传限制或临时错误。OneBot 的 `upload_group_file`/`upload_private_file` 只适用于 OneBot 适配器回退。

群文件清理管理员白名单内的 QQ 发送 `授权` 会生成 `https://club.vip.qq.com/transfer?open_kuikly_info=...` 授权链接；如果当前适配器取不到数字群号，可以发送 `授权 数字群号` 手动指定 `groupCode`；如果也取不到机器人 QQ，可以发送 `授权 数字群号 机器人QQ` 手动指定 `botUin`。插件会动态获取当前群号和机器人 QQ 号，机器人 QQ 会优先读取 AstrBot `context.robot_id`，并会递归读取事件 JSON、消息段 JSON 和 URL 编码 JSON 中的 `groupCode`、`botUin`、`botUid` 等字段；如果适配器不支持 UID 转换，会明确回复缺少机器人 UID。触发授权命令时会输出一条受控诊断日志 `授权链接事件诊断`，UID 转换接口有返回但无法识别时会输出 `授权链接UID转换响应未识别`。链接必须由群主在安卓/鸿蒙 QQ 9.2.90 及以上打开，iOS 暂不支持。
