# 馒头bot

适用于 AstrBot **QQ 官方机器人**的小说下载、网盘分享与群聊管理插件，提供独立网页控制台和 QQ 阅读开放 API。

## 主要功能

- **小说下载与找书**：识别平台分享链接和卡片，支持按书名、作者聚合搜索，生成 TXT。
- **小说交付**：UC、夸克、百度多账号分享；每群独立选择网盘账号，也可只对某个群关闭网盘、直接发送文件。
- **网页控制台**：管理多个机器人、阅读账号、网盘、小说开关、消息记录及群设置，支持手机和浅深主题。
- **群聊管理**：按群开启广告拦截，提供撤回、禁言、移除成员和黑名单管理，以及入群欢迎、使用教程。
- **聊天媒体归档**：原始图片、动画、视频、音频和附件归档到夸克，通过登录保护的网页代理读取。
- **QQ 阅读开放 API**：独立多 Key，支持整本、单章、多章和多本批量下载，无需 AppID。

插件不设激活、卡密、收费或每日免费次数。平台可读范围仍以接口、账号权限和实际返回为准，不保证付费、锁定或尚未发布的正文可下载。

## 安装与更新

1. 在 AstrBot WebUI 的插件管理中，用下面的仓库地址安装：

   ```text
   https://github.com/TimShitPig/mantou_Bot
   ```

2. 确认依赖已安装，完整依赖以 [requirements.txt](requirements.txt) 为准。主要包含 `aiohttp`、`httpx[http2]`、PyCryptodome、`gmpy2`、NumPy、`loky` 和 PyMySQL。
3. 配置 QQ 官方机器人、插件管理员、数据库和网页登录密码；需要网盘分享时再添加网盘账号。
4. 在插件管理中选择“管理 → 重载插件”，确认日志显示本次安装版本。

后续通过 GitHub 更新或重新安装。**重新安装前先等待当前上传结束**：缓存位于项目内部，替换插件目录可能删除未完成任务的文件。

已使用 Git 安装时，也可在实际插件目录执行 `git pull` 后重载。重载只读取服务器当前磁盘代码，不会自动拉取 GitHub；日志版本或行号未变化时，应先确认安装目录与代码，再考虑重启 AstrBot 容器。私有仓库需要有权限的 Git 凭据或 Deploy Key。

## 首次配置

AstrBot 插件配置页仅显示启动所需的 **9 项**：插件管理员、网页端口与登录账号/密码、MySQL 地址/端口/用户名/数据库名/密码。

其余设置登录插件网页后台后管理：

| 后台入口 | 设置内容 |
| --- | --- |
| 系统设置 | 网页监听地址、外网地址、登录信息、数据库 TLS/CA/超时等连接设置 |
| 机器人配置 | 当前机器人的管理员、教程图片宽度、ZLibrary 邮箱 API Key 与注册 rx |
| 网盘配置 | UC、夸克、百度账号、上传目录、默认账号及启停 |
| QQ 阅读账号 | Cookie、手机号/扫码登录、账号选择和会员资料 |
| QQ 阅读开放接口 | 服务公共开关、随机生成与撤销多个 Key |
| 消息记录 → 群菜单 | 当前群的网盘账号、文件直发和群管理 |

[_conf_schema.json](_conf_schema.json) 仍保留隐藏字段及默认值，避免升级或保存配置时丢失已有账号、Key 和 `bot_profiles` 机器人配置；隐藏不代表删除数据。无需手动编辑这些内部字段。

**数据库**：运行状态、账号与聊天记录使用 MySQL。数据库名留空时使用用户名；默认端口 3306、连接超时 10 秒。TLS 默认 `preferred`，也可选 `required`、`verify_identity`、`disabled`，认证或 TLS 失败不自动降级。系统设置可测试未保存表单，仅执行查询，不保存或建表；密码留空表示不修改，保存连接配置后重载生效。未配置数据库时不反复尝试连接，小说默认开启，主网盘默认 UC，账号、开关与历史不能获得完整持久化能力。

**网页**：默认监听 `0.0.0.0:8090`，自动生成服务器 IPv4 访问地址；Docker 需映射端口。配置管理员登录密码后访问 `http://服务器IP:8090`，也可填写完整 HTTP/HTTPS 外网地址供域名或反向代理使用。教程配图同样需要公网可访问，并转发 `/tutorial-images/` 路径；图片宽度默认 480，允许 160～1080。

**多机器人**：登录后先选择机器人。管理员、小说开关、测试模式、网盘账号与群选择、QQ 阅读账号、广告开关和布局按认证 AppID 隔离；数据库、网页监听、网页登录和开放 API Key 为服务公共设置。聊天列表、历史及群状态还按聊天类型、会话编号隔离。“退出机器人”返回选择页，“退出登录”结束管理员会话；停用机器人可配置，但不能借用其他机器人发送消息。

| 所有人 | `找关键词` / `找书 关键词` / `找书名 关键词` / `找作者 关键词` | 聚合找书，每页 5 条；`上一页`、`下一页` 翻页，`选1`～`选5` 下载 |
| 所有人 | `帮助`；群内单独 @机器人 | 公开菜单、小说列表、使用教程、添加机器人 |
| 插件管理员 | `帮助` / `状态` | 管理菜单与系统运行状态 |

| 插件管理员 | `开测试` / `关测试` | 管理员可测试关闭的平台，普通用户仍受开关限制 |
| 插件管理员 | `网盘` / `网盘状态` / `当前网盘`、`换UC` / `换夸克` / `换百度` | 查看或切换当前机器人的默认分享网盘 |
| 插件管理员 | `UC换N` / `夸换N` / `夸克换N` / `百换N` / `百度换N` | 切换当前群对应网盘的账号 |
| 插件管理员 | `关网盘` / `开网盘` | 仅当前群改为文件直发 / 恢复默认网盘 |

| 插件管理员 | `开广告` / `关广告` / `广告状态` | 当前群广告拦截，默认关闭 |

| 插件管理员 | `踢 @成员` / `@成员 踢` / `踢了 @成员` | 每次最多 20 人，默认不拉黑 |

含分享链接的输入先走链接识别，不会把 URL 参数当作书名送去搜索。找书结果按书名、作者匹配排序，同名同作者跨平台去重；找书会话按机器人、会话和用户隔离。

## 网盘、直发与缓存

### 小说交付

- 每次下载只用**一个**选定网盘；优先使用当前群覆盖，其次兼容旧群账号选择，再使用默认网盘及默认启用账号。百度不作为后台备份。
- 网页当前群“⋮ → 网盘账号”可选择账号或“关闭网盘，直接发送文件”。此设置只影响该群，不影响其他群、聊天媒体归档或开放 API。
- 文件直发先发原 TXT；官方完整响应明确拒绝后才尝试一次 ZIP，包内保留原文件名和原始正文。认证/权限拒绝、限流、超时或结果不明不自动改发，避免重复提交。
- 网盘成功后发送该平台的分享链接与“打开”按钮；失败只给固定短提示。后台区分正文、文件生成、上传和发送阶段，持续失败的上传文件由续传资料保护。

### 文件位置与清理

所有新缓存统一写入项目内 **`功能文件/文件缓存/`**，按小说、媒体、临时、消息记录和其他缓存分类，不再在项目外创建 `mantou_bot_file_cache/`。旧外部缓存兼容迁移，活动任务暂留原路径；不要手动删除正在使用的 TXT、`.uploading` 或 `.upload_jobs`。

UC、夸克、百度以配置目录为总目录，小说上传进入 `总目录/YYYY年M月D日/`。每天服务器本地零点清理前两天及更早的小说 TXT，保留今天、昨天和活动/待续传文件；远端只删除已确认空的过期日期目录，不删除总目录或其他文件。启动/重载也清理无占用残留。

夸克 OSS 分片对 408/429/500/502/503/504、断流、超时最多尝试三次，每次重开文件、刷新签名；只重试同一上传 ID 和分片号，不盲目重放预上传、合并、完成或创建分享。权限/签名拒绝不循环重试。

### 聊天媒体

媒体归档使用消息所属机器人的**默认且启用的夸克账号**，目录为 `/QQ聊天媒体/YYYY年M月D日/`，不参与小说清理。按消息时间的本地日期归档，无有效时间使用当天；原文件不转码、不压缩，保留动画，单项上限 5 GiB，同时最多两路任务。

更换默认账号只影响新任务；历史归档绑定原账号，删除该账号可能影响读取。网页仅通过登录保护的同源代理读取，音视频支持 Range，普通文件按原名下载。缺少源地址的附件仍显示名称和大小，但不构造地址或发起归档；明确过期的源停止旧地址重试。旧蓝奏云归档只读兼容，不再提供新上传或批量迁移。

## 网页消息记录与群管理

- 登录后管理当前机器人：收发消息、查看历史/原始数据、引用定位、搜索提及、附件、备注和群设置。消息右键/长按提供复制、引用、撤回等操作，键盘支持 Shift+F10；切群或切机器人废弃旧响应。
- 聊天三栏可拖动尺寸并按机器人保存，支持浅深主题、手机布局、回到底部及引用后返回最新消息。群角色未知时不据展示标签推断权限。
- MySQL 历史不按条数或时间自动删除；内存和网页分页上限不等于保存上限。手动清理或删除会话先预览再确认，保留预览后的新消息，不撤回 QQ 消息、不删除群资料或网盘文件。
- 广告拦截仅当前群生效，默认关闭。群主、群管理员和普通 @消息放行；普通成员命中数字/卡片等规则后，最多联动撤回本群该用户截至触发消息的 30 条已记录消息。自动拦截不会踢人，禁言次数可跨群累计，处罚只作用当前群。
- 撤回是否成功、权限和时限均以 QQ 官方响应为准；不将入退群系统通知编号当成消息 ID，不宣称突破平台时限。群成员/黑名单操作每次最多 20 人，写请求不盲目重放。
- 群状态、资料、人数与好友关系根据可信事件和接口结果更新，保留历史；陌生昵称和身份关联不按名字、头像或相邻消息猜测。

## QQ 阅读开放 API

在插件网页后台开启 QQ 阅读开放接口，随机生成并添加 Key。支持多个 Key、单独撤销；新 Key 只展示一次，已有 Key 不回显。服务复用帮助网页地址，前缀为 **`/openapi/qq-reader/v1`**。

浏览器可直接访问以下入口，示例需替换地址、Key 和书籍 ID：

```text
http://服务器IP:8090/openapi/qq-reader/v1/download?key=你的Key&book_id=书籍ID
http://服务器IP:8090/openapi/qq-reader/v1/chapter?key=你的Key&book_id=书籍ID&chapter=1
http://服务器IP:8090/openapi/qq-reader/v1/chapters?key=你的Key&book_id=书籍ID&chapter_range=1-1000
```

整本返回 UTF-8 TXT，单章和多章直接返回带原目录序号、标题、正文的 JSON，不创建网页。章节参数用完整目录的 **1 起始序号**，无需章节 ID；支持 `1-n`、`101-n` 和数字终点，终点超过现有目录取到末章，起点超出则失败，不等待虚构章节。

程序调用使用 `Authorization: Bearer <API_KEY>`，无需 AppID 或控制台 Cookie：

| 方法与路径（相对前缀） | 请求或返回 |
| --- | --- |
| `POST /tasks` | `{"book_id":"123456","chapter_range":"1-n"}` |
| `POST /tasks/batch` | `{"book_ids":["123456","234567"],"chapter_range":"1-n"}`；也支持单个 `book_id` |
| `GET /tasks/{task_id}` | 查询任务状态 |
| `GET /tasks/{task_id}/file` | 用同一 Key 获取成功任务的 TXT |

仅上述三个浏览器 GET 入口接受 URL `key`，其他接口仍须 Bearer。不同 Key 的任务隔离；撤销 Key 会结束相关等待。未限制批量书籍/排队数量，固定两路下载，正文超时 30 分钟，单文件上限 64 MiB，结果保留 1 小时。

账号识别以**实际选中的 QQ 阅读账号**为准：只有一个机器人选中账号时可复用，即使配置了多个机器人；没有选中账号或多个机器人均选中账号时匿名，不借用首实例。每批固定账号，复用任务同时校验账号、章节范围和结果格式，登录后不复用旧匿名结果。API 不发送 QQ 消息或上传网盘；同进程重载保留任务，进程重启需重新提交。

## 排错与维护

| 现象 | 核对方式 |
| --- | --- |
| GitHub 已更新但仍是旧行为 | 检查实际插件目录和启动版本；拉取/重装之后再重载，必要时重启容器 |
| `rate_limit_check.stage`、会话被暂停 | AstrBot 核心限流；检查当前平台实际使用的 `platform_settings.rate_limit`，`stall` 等待、`discard` 丢弃 |
| 群资料刷新受限 | `bot_state`、`info` 各 30 次/分钟，按 AppID/接口共享；强制刷新不绕过配额和失败冷却 |
| 群状态被标记已移除 | 可信退群事件，或 HTTP400/SDK 缺失 HTTP 时完整码对 `11255/40011028`、`11293/40011026`；429、权限、认证、网络失败不能据此判离群 |
| 凭据错误 `100016` | 检查当前 QQ 官方平台 AppID/ClientSecret；认证通道冷却 60 秒，保留状态与历史 |
| 下载/发送失败 | 核对同一任务的阶段、数字状态码和版本；不要只凭目录数量差异、单次超时或 Event loop lag 猜原因 |

同进程热重载交接原事件、选书结果、账号、TXT、媒体进度和已确认发送状态，避免重复发送。进程重启仅恢复已有落盘 TXT 的上传续传，不保证恢复未完成正文或纯内存媒体任务。数据库配置、账号或登录凭据改变后，旧网页登录/扫码会话失效。

QQ 阅读在下载或主动刷新资料时核对登录状态。官方明确返回未登录后，后台账号卡片和详情显示“登录已失效，请重新登录”，下载提示联系管理员重新登录；网络超时不会标记失效。重新保存账号后恢复待验证，验证成功恢复正常状态。

QQ 阅读搜索支持展开系列书单中的单本书，不把系列编号当作书籍编号。指定 QQ 阅读搜索遇到空响应、格式异常或超时时提示“搜索失败，请稍后再试”，不缓存为无结果；正常空列表仍提示没有相关书籍，候选目录与免费章节校验保持不变。
